## 2026-09-24 · Синие цвета игроков похожи на воду · предложение агента

- **Что:** проверить ΔE2000 заливок игроков (`mix(line, #FFF, fillMix)` при `alphaOther`/`alphaOwn` поверх равнины) против `map.water`; цвета ниже порога — сдвинуть по оттенку или исключить из соседства с водой.
- **Почему:** на скриншотах `cobalt` (южное государство) читается как озеро; то же ожидается у `ocean`, `cyan`, `navy`, `steel`, `indigo`.
- **Файлы:** `art/tokens.json` (`players.palette`), тест в `apps/client/test/terrain-palettes.test.ts`.
- **Влияние:** только клиент; эталоны скриншотов.

## 2026-09-29 · Эволюционный подбор параметров бота · идея владельца, после плейтеста (T27)

- **Что:** `tools/evolve` — подбор порогов бота (`10-balance.md`, «Боты») эволюционной стратегией (μ,λ)-ES без внешних зависимостей: особь — вектор порогов; оценка — матчи на 20+ сидах против популяции прошлых поколений (не против фиксированного бота), параллельно на `worker_threads`; результат — лучшая особь и отчёт по поколениям.
- **Почему:** пороги бота подобраны вручную (`[ТЮНИНГ]`); после плейтеста нужен воспроизводимый способ их улучшать.
- **Файлы:** новый `tools/evolve/`, `docs/architecture/adr/` (если понадобится новая зависимость — не планируется), `10-balance.md` (итоговые значения — коммитом `balance:` с метриками до/после).
- **Когда:** не раньше плейтеста владельца (04/T27).

## 2026-10-02 · Склады на своей территории с автодорогой · предложение владельца, этап 05

- **Что:** склад можно строить на любом своём гексе. Если гекс вне основной сети, вместе со складом прокладывается дорога до сети по правилам «Проложить дорогу»; цена считается за каждый гекс без готовой дороги. Склад не меняет рост населения.
- **Почему:** снабжать дальние фронты без ручного строительства отдельных дорог.
- **Файлы:** этап 05 и код снабжения/строек после утверждения; GDD не изменяется до отдельного решения владельца.
- **Влияние:** этап 05; нужны команды, валидация пути и цены, состояние стройки, UI и тесты. Снабжение дальних фронтов должно учитывать автоматически проложенную дорогу.
