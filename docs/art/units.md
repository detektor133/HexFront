# Знаки отрядов и маркеры карты

Все размеры заданы в px **при масштабе карты 1** и масштабируются вместе с картой, как знаки городов: при приближении фишка растёт, при отдалении уменьшается, соотношение с гексом постоянно (решение владельца 2026-09-25). Текст растеризуется в разрешении текущего масштаба × `devicePixelRatio`, чтобы оставаться чётким. Эталон — скриншот-тест `client/tests/visual/units.spec.ts` (страница `/dev/units` со всеми состояниями).

## Фишка отряда

Фишка — это отряд (CR-001). Армия — группа отрядов — отдельной фишки не имеет: при выборе армии её отряды получают состояние «Выбрана», а её участок фронта подсвечивается.

```
 ┌──────────────────────┐   высота 24, радиус 6
 │ [глиф 14×14]  1,4к   │   отступ слева 6, глиф–число 5, справа 8
 └──────────────────────┘   мин. ширина 44
 ▀▀▀▀▀▀▀▀▀▀▀▀▀▀▀          полоска организованности 2 px, отступ 2 под фишкой
```

| Параметр | Значение |
| --- | --- |
| Высота | 24 |
| Радиус | 6 (`radius.chip`) |
| Заливка | По отношению к игроку (`relation`, CR-003): свои `relation.own`, союзники `relation.ally`, враги `relation.enemy` |
| Обводка | 1,5 px `#FFFFFF` снаружи (отделяет фишку от территории того же цвета) |
| Глиф | 14×14, белый, stroke 2, round cap/join, начало в (6, 5) |
| Число | Golos Text 500, 12 px, белый, tabular-nums, базовая линия y = 16,5 |
| Ширина | `max(44, 6 + 14 + 5 + ширина_текста + 8)`, округлить вверх до чётного |
| Организация | Внутри фишки — по варианту (ниже, «Армия и варианты фишки») |

### Формат числа

| Солдат | ru | en |
| --- | --- | --- |
| 1–999 | `850` | `850` |
| 1 000–9 999 | `1,4к` | `1.4k` |
| 10 000+ | `12к` | `12k` |

Округление вниз (показываем не больше, чем есть).

### Глифы (сетка 14×14, stroke 2)

| Тип | Геометрия | Смысл формы |
| --- | --- | --- |
| Пехота | Шеврон: ломаная (2,10) → (7,5) → (12,10) | «Строй», направленность вперёд |
| Бронетехника | Ромб: (7,2) (12,7) (7,12) (2,7), замкнут | Острый прорыв |
| Артиллерия | Полуокружность от (2,10) до (12,10) через (7,5) + залитая точка r = 1,75 в (7,10) | Дуга траектории, радиус огня |

Глифы — векторные пути в `client/src/render/glyphs.ts`, **не** иконки из шрифтов и не SVG-файлы из интернета.

### Устройство фишки (CR-005)

Всё — внутри прямоугольника фишки 26 px высотой, ничего не выходит наружу:

| Часть | Вид |
| --- | --- |
| Закладка армии | Полоса 6 px цвета армии по левому краю; у резерва и чужих отрядов нет |
| Квадрат | 24×26, цвет по отношению (`relation`: свои — зелёные, враги — красные, союзники — синие), белый глиф рода войск |
| Стопка | Если в гексе несколько отрядов — белый кружок ⌀10 с цифрой 8 px в правом нижнем углу квадрата (глиф сдвинут на 2,5 px вверх-влево) |
| Нехватка снабжения | Треугольник 8 px в правом верхнем углу квадрата: `status.lowSupply` — ниже 50 %, `status.danger` — идёт истощение |
| «Держать» | Белая полоска 9×2 внизу квадрата |
| Плашка | Белая, число солдат `ui.ink` 12 px 600 |
| Столбики | Два вертикальных 4 px справа: организация `chip.org`; снабжение `chip.supply`, ниже 75 % — `status.lowSupply`, ниже 50 % или при истощении — `status.danger`; подложка `chip.track`. У чужих — только организация |
| Обводка | 1,5 px цвета отношения; выбрано — золото `selection.color` 2,5 px; котёл — `status.encircled` 2 px |

### Состояния

| Состояние | Отображение |
| --- | --- |
| Обычное | Как выше |
| Выбрана | Обводка фишки — золото `selection.color` 2,5 px (по краю, не снаружи), масштаб 1,06 (CR-005) |
| В бою | Маркер боя между гексами (ниже); фишка сдвинута на 3 px к противнику |
| Низкое снабжение (< 50 %) | Треугольник 8 px `status.lowSupply` в правом верхнем углу квадрата; идёт истощение — `status.danger` |
| Котёл (0 %, нет пути) | Кольцо 2 px пунктир 3/3 `status.encircled` вокруг фишки + точка как выше, красная |
| Отступает | Прозрачность 60 %, диагональная белая штриховка 30 % поверх заливки, движется без интерполяции «назад» (ease-out быстрый) |
| Строится/набирается | Фишка-призрак в городе: обводка пунктиром `line`, без заливки, число = заказанное |
| Приказ hold | Короткая горизонтальная черта 2 px под полоской org |

### Несколько отрядов в гексе

- z1 и z2: одна агрегированная фишка на гекс: глиф преобладающего типа, сумма солдат, справа маленькая цифра-индекс количества отрядов (`×3`, 10 px). Одна армия — обычная фишка без индекса.
- z3 или тап по агрегированной фишке: до 3 фишек стопкой по вертикали, шаг 26 px, центр стопки = центр гекса.

## Маркер боя

- Круг ⌀16 на середине общего ребра гексов, заливка `#FFFFFF`, обводка 2 px `ui.ink`.
- Внутри два коротких диагональных штриха 2 px крест-накрест (7 px).
- Пульс масштаба 1,0 → 1,15, период 800 мс.
- По тапу — плашка прогноса/текущего хода боя.

## Плашка прогноза

- Карточка: фон `ui.surface`, обводка 1,2 px цвета исхода (`status.success` / `status.warning` / `status.danger`), радиус 6, `shadow.hard`.
- Текст 12 px: «Победа · потери ~28 %», «Упорный бой · ~45 с», «Поражение».
- Размещение: у конца стрелки или над целевым гексом, не перекрывает фишки.

## Линии планов

- Участок фронта — по граням своей границы, ширина `front.width[z]` (2,5–3,5 px), цвет армии на белой подложке `front.casing`; у выбранной армии — белые ручки ⌀`front.handleRadius`×2 с обводкой цвета армии на концах (CR-004).

### Линия наступления

- Линия «до куда» (07-controls.md, «Линия наступления») — по граням, сглаженная (Чайкин, 2 прохода), цвет `arrow.color`, ширина `arrow.width[z]`; нарисованная — пунктир `arrow.dash`, идущая — сплошная (CR-005).
- От фронта к линии — 1–3 полупрозрачные стрелки (`arrow.alpha`, у нарисованной — `arrow.plannedAlpha`), как в HoI4: тело `arrow.bodyWidth`, наконечник `arrow.headLength` × `arrow.headWidth` радиуса гекса; число — по длине фронта (одна на ~3 гекса), начала и концы равномерно вдоль фронта и линии в одном порядке — стрелки не сходятся и не пересекаются. 
- Кольцо деления (вытягивание из фишки, CR-005): подложка белая 8 px, дуга `relation.own` 5 px от верха по часовой, ручка ⌀12, число над кольцом; путь в гекс — пунктир `relation.own`.
- Заливки зоны наступления нет.
