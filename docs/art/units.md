# Знаки отрядов и маркеры карты

Все размеры заданы в px **при масштабе карты 1** и масштабируются вместе с картой, как знаки городов: при приближении фишка растёт, при отдалении уменьшается, соотношение с гексом постоянно. Текст растеризуется в разрешении текущего масштаба × `devicePixelRatio`, чтобы оставаться чётким. Вид проверяет владелец по предпросмотру ветки.

## Фишка отряда

Фишка показывает отряд или группу отрядов одного игрока в одном месте карты (ниже, «Группа отрядов»). Армия отдельной фишки не имеет: её показывает закладка на фишках её отрядов.

Всё — внутри прямоугольника фишки высотой 26 px, радиус `radius.chip`; ничего не выходит наружу:

```
 ┌─┬──────┬─────────────┬──┐
 │▌│  ^   │    1,4к     │▮▮│   высота 26
 │▌│    ② │             │▮▮│
 └─┴──────┴─────────────┴──┘
 закладка · квадрат 24×26 · плашка с числом · столбики
```

| Часть | Вид |
| --- | --- |
| Закладка армии | Полоса 6 px цвета армии по левому краю; у резерва и чужих отрядов нет |
| Квадрат | 24×26, цвет по отношению к игроку (`relation`: свои `relation.own`, союзники `relation.ally`, враги `relation.enemy`), белый глиф рода войск по центру |
| Цифра группы | Если в фишке больше одного отряда — белый кружок ⌀10 с цифрой 8 px в правом нижнем углу квадрата (глиф сдвинут на 2,5 px вверх-влево); видна всегда, в том числе на марше |
| Нехватка снабжения | Треугольник 8 px в правом верхнем углу квадрата: `status.lowSupply` — ниже 50 %, `status.danger` — идёт истощение |
| Плашка | Белая, число солдат `ui.ink`, Golos Text 600, 12 px, tabular-nums, по центру плашки |
| Столбики | Два вертикальных 4 px справа: организация `chip.org`; снабжение `chip.supply`, ниже 75 % — `status.lowSupply`, ниже 50 % или при истощении — `status.danger`; подложка `chip.track`. У чужих — только организация |
| Обводка | 1,5 px цвета отношения |

Ширина фишки — закладка + квадрат + плашка по ширине числа + столбики; фишка не меняет высоту и не выходит за свой прямоугольник ни в одном состоянии.

### Формат числа

| Солдат | ru | en |
| --- | --- | --- |
| 1–999 | `850` | `850` |
| 1 000–9 999 | `1,4к` | `1.4k` |
| 10 000+ | `12к` | `12k` |

Округление вниз (показываем не больше, чем есть).

### Глифы (сетка 14×14, stroke 2, round cap/join)

| Тип | Геометрия | Смысл формы |
| --- | --- | --- |
| Пехота | Шеврон: ломаная (2,10) → (7,5) → (12,10) | «Строй», направленность вперёд |
| Бронетехника | Ромб: (7,2) (12,7) (7,12) (2,7), замкнут | Острый прорыв |
| Артиллерия | Полуокружность от (2,10) до (12,10) через (7,5) + залитая точка r = 1,75 в (7,10) | Дуга траектории, радиус огня |

Глифы — векторные пути в `client/src/render/glyphs.ts`, **не** иконки из шрифтов и не SVG-файлы из интернета.

### Состояния

| Состояние | Отображение |
| --- | --- |
| Обычное | Как выше |
| Выбрана | Обводка — золото `selection.color`, `selection.width`, по краю фишки, без изменения размера |
| В бою | Маркер боя между гексами (ниже); фишка сдвинута на 3 px к противнику |
| Низкое снабжение (< 50 %) | Треугольник `status.lowSupply` в углу квадрата; идёт истощение — `status.danger` |
| Котёл (0 %, нет пути) | Обводка `status.encircled` 2 px по краю фишки |
| Отступает | Прозрачность 60 %, диагональная белая штриховка 30 % поверх заливки, движется без интерполяции «назад» (ease-out быстрый) |
| Строится/набирается | Фишка-призрак в городе: обводка пунктиром `line`, без заливки, число = заказанное |

Если состояний несколько, у обводки порядок: выбрана > котёл > обычная.

### Группа отрядов

- Одна фишка — все отряды одного игрока в одном месте карты: стоящие в одном гексе или идущие одним переходом (из того же гекса в тот же гекс с одинаковым прогрессом). Цифра в углу — число отрядов в фишке.
- Группа не распадается на отдельные фишки ни в начале перехода, ни на гексе пути между переходами, ни в ожидании перед полным гексом. Отряды, которые разошлись (разная скорость, разные пути), — разные фишки.
- Глиф — род войск с наибольшим числом солдат в группе; число — сумма солдат; столбики — средние по солдатам.
- Закладка армии — если все отряды группы из одной армии; иначе без закладки.
- Одинаково на всех уровнях детализации.

## Маркер боя

- Круг ⌀16 на середине общего ребра гексов, заливка `ui.surface`, обводка 2 px `ui.ink`.
- Круг разделён на два сектора цветами `players.palette[].line` двух сторон боя; доля сектора стороны = её суммарная организованность / сумма организованностей обеих сторон в бою.
- Граница секторов — линия 1,5 px `ui.surface`.
- Доля квантуется на 8 состояний (шаг 12,5 %); готовые состояния создаются один раз и переиспользуются, маркер не перерисовывается каждый тик и перерисовывается только при смене состояния.
- Нет данных об организованности в снимке — добавь поле в вид (минимальное, дельтой, см. 07/T15); нет данных вовсе — круг нейтрального цвета `ui.border`.
- Пульс масштаба 1,0 → 1,15, период 800 мс.
- По тапу — плашка текущего хода боя.

## Плашка прогноза

- Плашка не висит постоянно. У конца линии наступления выбранной армии — только иконка исхода 14×14 (галочка / «равно» / провал) цвета `status.success` / `status.warning` / `status.danger`, без числа и без карточки.
- Число потерь «−28 %» — карточка плашки по прежней спецификации (`ui.surface`, обводка цвета исхода, `shadow.hard`) только при наведении на иконку на ПК или при долгом тапе на телефоне.
- Тап по маркеру боя открывает плашку текущего хода боя.
- Числа плашки — `BitmapText` (07/T15).

## Линии планов

### Линия фронта

- По граням своей границы, ширина `front.width[z]`, цвет армии на белой подложке `front.casing` (`front.casingWidth`). В тумане линия приглушается до `tokens.fog.memoryAlpha`; выбранная армия рисуется с `alpha=1` и шириной следующего уровня `front.width[z]`, зажатой на последнем уровне.
- У выбранной армии — белые ручки ⌀ 2 × `front.handleRadius` с обводкой цвета армии на внешних углах концевых граней.
- Сдвиг фронта за границей — плавный переход линии за 250 мс.

### Линия обороны

- Та же линия по центрам гексов линии, с короткими «зубцами» в сторону врага (`armies.defenseTeeth`).

### Линия наступления

- Линия «до куда» (`gdd/07-controls.md`, «Линия наступления») — гладкая кривая: опорные точки — середины её граней, сглаженные (2–3 прохода Чайкина), концы — на концах линии; через сами середины кривая не обязана проходить — на гексах с плоской вершиной они идут волной, и кривая бы её повторила; цвет `arrow.color`, ширина `arrow.width[z]`. Нарисованная — пунктир `arrow.dash`, идущая — сплошная.
- От фронта к линии — 1–3 стрелки (`arrow.color`; нарисованная линия, до ▶, — полупрозрачные `arrow.plannedAlpha`, идущая, после ▶, — насыщенные `arrow.alpha`): тело `arrow.bodyWidth`, наконечник `arrow.headLength` × `arrow.headWidth` радиуса гекса. Стрелки путей движения своих отрядов видны всегда, у выделенной армии — акцентно; чужие стрелки не показываются. Линия тонкая, цвета игрока, а число стрелок ограничено и не растёт без границ. Хвосты — только на участке текущего фронта, смотрящем на линию (`gdd/07-controls.md`), не внутри страны и не на противоположной стороне; хвосты едут за фронтом, стрелки укорачиваются по мере продвижения. Число стрелок = clamp(округл(ширина смотрящего участка в гексах / 4), 1, 3). Точки на смотрящем участке и на линии — равномерно по длине кусков, соединяются по порядку (1-я с 1-й, 2-я со 2-й), без перескоков через разрывы; стрелки не пересекаются (если на изогнутых кусках две пересеклись — они меняются концами).
- Заливки гексов наступления нет.

### Деление вытягиванием

- Кольцо вокруг фишки: подложка белая 8 px, дуга `relation.own` 5 px от верха по часовой, ручка ⌀12, число над кольцом; путь в гекс — пунктир `relation.own`.
