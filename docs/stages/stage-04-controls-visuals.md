# Этап 04 — Управление и финальный визуал

**Цель:** игра выглядит и управляется как продукт: стиль «метро-карта» полностью, фишки по спецификации, автофронт и стрелки наступления, HUD с налогом, карточки города и армии (включая «Перестроить снабжение»), удобно с телефона.

**Читать:** `art/*` целиком, `gdd/07-controls.md`, `gdd/06-combat.md` (прогноз), `gdd/08-match.md` (туман).

## Задачи

- [ ] **T1. `frontSystem` + `frontAllocator`** (sim): фронты по соседям-врагам, армия на фронте (`assignFront(armyId, enemyId)`, CR-001), деление фронта на участки нескольких армий пропорционально солдатам, распределение отрядов армии (пехота/броня на линию, артиллерия позади), возврат отряда армии на участок после ручного приказа, порог перестановки 15 %; нуждаемость автопополнения — солдаты на гекс участка.
- [ ] **T2. `offensiveSystem`** (sim): стрелки армий (`arrow(armyId, points)`, `arrowStop`), выбор шага по оси и прогнозу, остановка при org < 30, максимум 3 стрелки.
- [ ] **T3. `visionSystem` + `playerView` с туманом и памятью** (в локальном режиме клиент получает только видимое).
- [ ] **T4. Слои карты** по таблице слоёв `style-guide.md`: территория с fillMix и alphaOwn/alphaOther, узоры рельефа над территорией (слой 4а), двухцветные границы, туман-штриховка, дороги пунктиром (изолированные — серые, `style-guide.md`), стройки «муравьями», города-станции с уровнями/столицей/изоляцией/прогрессом, подписи с ореолом, фронт, стрелки. Статические слои кэшируются в RenderTexture.
- [ ] **T5. Фишки отрядов** строго по `units.md`, подсветка отрядов выбранной армии, все состояния, агрегация на z1/z2, стопки на z3 и по тапу. Страница `/dev/units` со всеми состояниями — эталон скриншот-теста.
- [ ] **T6. Маркер боя, плашка прогноза, анимации** (захват, вспышка города, контур котла), `prefers-reduced-motion`.
- [ ] **T7. HUD** — основа сделана в 02/T11 (люди, золото, налог, таймер, место); здесь — снабжение основной сети с отрядами, адаптив альбома 844×390, анимации.
- [ ] **T8. Карточка отряда и панель армий** (`07-controls.md`: создать, переименовать, расформировать, на фронт, резерв, «Автопополнение»; карточка гекса и города — 02/T11), кнопки с причинами отказа, «Перестроить снабжение» с подсветкой пути на карте, набор отрядов (тип, ползунок, время).
- [ ] **T9. Жесты и мышь** по таблице `07-controls.md`, рисование стрелки пальцем с упрощением до ≤ 4 точек, горячие клавиши. Touch-цели ≥ 44 px.
- [ ] **T10. Лента событий** и камера к событию по тапу.
- [ ] **T11. Визуальные тесты** `/dev/units`, `/dev/map`, `/dev/ui`, экран матча — 3 разрешения × DPR 1/3.
- [ ] **T12. Производительность**: 60 fps на ПК, ≥ 45 fps на среднем Android (Chrome, remote debugging) на карте 4000 гексов, замеры в отчёт.

## Приёмка владельцем (обязательно, агент не может закрыть сам)

Владелец смотрит скриншоты и играет 10 минут в песочнице на телефоне. Проверка по чек-листу «не выглядит как нейросеть» из `style-guide.md` + вопросы:
- Видно ли котёл за 1 секунду без зума?
- Различаются ли типы войск на телефоне?
- Можно ли вести войну только стрелками и автофронтом?

Замечания → задачи `T13+` в этом же этапе.

## Вне объёма

Главное меню и лобби (кроме заглушки «Играть» → песочница), боты, сервер, звук.
