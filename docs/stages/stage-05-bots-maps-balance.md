# Этап 05 — Боты, генератор карт, баланс, плейтест (GO / NO-GO)

**Цель:** полноценный оффлайн-матч против 20–40 ботов на сгенерированной карте, темп матча соответствует целям, решение владельца продолжать ли проект.

**Читать:** `gdd/09-bots.md`, `gdd/01-map.md`, `gdd/00-overview.md` (темп), `gdd/10-balance.md`.

## Задачи

- [ ] **T1. Процедурный генератор** (`packages/mapgen`): целочисленный value-noise, континенты, реки, биомы, особые гексы, нейтральные города (дистанция ≥ 4), дороги (MST + 20 % рёбер Делоне), спавны (Poisson-disc ≥ 10). Параметр — число игроков.
  *Приёмка:* 100 сидов → все карты проходят валидатор, у каждого спавна ≥ 15 проходимых гексов в радиусе 2 и путь по суше к ≥ 2 соседям; галерея превью 12 сидов в отчёт.
- [ ] **T1a. Стенд плейтеста** (только dev-инструмент, механику `sim` не менять): `/dev/sandbox` принимает `map=gen&seed=N&players=2..30`, карта берётся из генератора T1 с указанным числом спавнов; без `map` сохраняется прежняя `small`. Добавить панель наблюдателя: пауза, шаг на 1 тик, скорость 1/5/20×, выбор вида любого игрока или всей карты без тумана. Добавить таблицу лидеров по всем игрокам: гексы, города, солдаты, золото, жив/выбыл; обновление раз в секунду. `pnpm report:match --map gen --players 30` должен сохранять таймлапс территории: кадр раз в минуту матча, одна PNG-сетка в `docs/reports/match/seed-N/`.
  *Приёмка:* матч 30 ботов на сгенерированной карте открывается в песочнице и идёт на скорости 5× без отставания тиков на ПК; таймлапсы 3 сидов включены в отчёт этапа.
- [ ] **T2. Карта «Европа».** Импорт рельефа/береговой линии/рек из общественного достояния (Natural Earth, public domain) скриптом `packages/mapgen/import/`, проекция и гексагонизация, вымышленные названия городов. Исходные данные не коммитить, коммитить результат JSON и скрипт.
- [ ] **T3. Боты** по `09-bots.md`: военная часть — commander (готов в 04, CR-006), экономический мозг — тоже в 04; здесь — уровни ботов и utility AI поверх commander и экономического мозга, только через команды и `playerView`.
- [ ] **T4. `tools/balance`**: headless-прогон N матчей ботов параллельно (worker_threads) на сгенерированных картах для 30 игроков, до правок ботов и баланса; метрики: длительность, доля нейтральных гексов на 3:00, минута первого боя, число котлов, распределение мест по стартовым позициям, среднее население/золото по времени; отчёт markdown + CSV.
- [ ] **T5. Итерации баланса**: цель — метрики темпа из `00-overview.md`. Каждое изменение чисел — коммит `balance:` с метриками до/после. Изменения чисел > ±30 % от исходных — вопрос владельцу в `QUESTIONS.md`.
- [ ] **T5a. Содержание и число отрядов.** Убрать глобальный лимит отрядов игрока; сохранить максимум 3 отряда в гексе, минимум набора 50 и одну очередь набора на город. Добавить содержание `UPKEEP_GOLD_PER_UNIT_S` в расходы игрока, банкротство, набор и экономические решения ботов; автоделение ограничивается только `FRONT_SPLIT_MIN` и свободным местом в гексе.
  *Приёмка:* нет отказа `unitLimit`; playerView и тексты интерфейса не показывают глобальный лимит; деление и набор работают без потолка при свободном гексе; расходы и банкротство учитывают содержание за солдата и за отряд; бот учитывает оба расхода в бюджете набора; 3 отряда в гексе, минимум 50 и одна очередь на город сохраняются.

Правила отрядов и набора** (подсистема `sim`, зависит от T5a): удалить отказ `unitLimit`; сохранить до 3 отрядов одного игрока в гексе, минимум набора 50, одну очередь набора на город и автоделение только по `FRONT_SPLIT_MIN` и свободному месту. Проверить краевые случаи свободного и заполненного гекса.
  *Приёмка:* команды набора и деления работают без глобального потолка при свободном месте; заполненный гекс не принимает четвёртый отряд; минимум набора 50 и одна очередь на город сохраняются.
- [x] **T5a2. Содержание в экономике** (подсистема `sim`, зависит от T5a1): учитывать `UPKEEP_GOLD_PER_UNIT_S` в расходах игрока и отрицательном балансе банкротства; удалить старое ограничение отрядов из связанных экономических проверок.

## GO / NO-GO (решает владелец)

Плейтест: 5 человек, которые не видели игру, по 3 матча на телефоне без объяснений.

| Критерий | Порог GO |
| --- | --- |
| Доиграли первый матч до конца или выбывания | ≥ 4 из 5 |
| Сами захотели сыграть 3-й матч | ≥ 3 из 5 |
| Поняли, что такое котёл, без объяснений | ≥ 3 из 5 |
| Средняя длительность матча | 15–25 мин |

NO-GO → переделка управления/темпа, этапы 06+ не начинаются.
