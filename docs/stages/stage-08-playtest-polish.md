# Этап 08 — Плейтест и доводка

**Цель:** решение владельца GO / NO-GO и доводка интерфейса и геймплея по замечаниям плейтеста (CR-008).

**Читать:** `docs/01-vision.md`, `gdd/07-controls.md`, `art/ui.md`, `docs/BUGS.md` (Б3).

## Задачи

- [ ] **T1. Плейтест GO / NO-GO** (задача владельца, раздел перенесён из этапа 05 дословно). Плейтест: 5 человек, которые не видели игру, по 3 матча на телефоне без объяснений.

| Критерий | Порог GO |
| --- | --- |
| Доиграли первый матч до конца или выбывания | ≥ 4 из 5 |
| Сами захотели сыграть 3-й матч | ≥ 3 из 5 |
| Поняли, что такое котёл, без объяснений | ≥ 3 из 5 |
| Средняя длительность матча | 15–25 мин |

  *Приёмка:* решение GO / NO-GO и замечания плейтеста записаны владельцем в `DECISIONS.md`.
- [ ] **T2. Доводка по замечаниям.** Владелец утверждает список правок интерфейса и геймплея через `$decide`; каждая правка — задача T2a, T2b… со своим критерием приёмки. Сюда же — открытые Б3 из `BUGS.md`. Задачи вне утверждённого списка не добавляются.
  *Приёмка:* все задачи утверждённого списка отмечены `[x]`.

## Порядок

T1 → T2.

## Вне объёма

Мультиплеер, порталы, новые механики без CR.

## Готово, когда

Решение GO / NO-GO записано в `DECISIONS.md`, все задачи списка T2 отмечены `[x]`. При NO-GO следующий шаг решает владелец.
