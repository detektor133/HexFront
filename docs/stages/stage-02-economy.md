# Этап 02 — Территория, экономика, города, снабжение

**Цель:** работающее «государство» без войны: население растёт вокруг городов, налог влияет на рост и золото, города основываются и улучшаются, дороги строятся, сети снабжения и изоляция считаются, перестройка снабжения работает. Всё в `sim`, с минимальной отладочной визуализацией.

**Читать:** `gdd/02-economy.md`, `gdd/03-cities-buildings.md`, `gdd/04-roads-supply.md`, `gdd/10-balance.md`, `architecture/sim-core.md`, `testing.md`.

## Задачи

- [x] **T1. `balance.ts`** — выполнено в 01/T4 (все разделы `10-balance.md`; тест сверяет имена констант с документом, что строже сверки количества). Исходная формулировка: все константы из `10-balance.md` (разделы «Время», «Местность», «Население и налог», «Города и постройки»). Тест сверяет количество констант с таблицами (парсит markdown).
- [x] **T2. `taxSystem` + команда `setTax`.** Диапазон, шаг, инерция 2 п.п./с, `taxGrowthMult`.
  *Приёмка:* налог 0/20/40 → 1,4/1,0/0,5; с 20 % на 40 % за 10 с; невалидные ставки отклоняются.
- [x] **T3. `populationSystem`.** Лимиты, рост по кольцам с максимумом по городам, уровни городов, благоустройство, убыль сверх лимита, множитель изоляции.
  *Приёмка:* сценарии: гекс в кольце 1 двух городов берёт максимум; гекс вне радиуса не растёт; рост замедляется к лимиту; инвариант «нет создания из ничего».
- [x] **T4. `economySystem`.** Доход (налог, города, шахты), изоляция ×0,5. Банкротство и содержание армий — на этапе 03.
  *Приёмка:* стартовый доход на `small` ≈ +1,06/с (±5 %).
- [x] **T5. Стройки** (`constructionSystem`): `foundCity`, `upgradeCity`, `improve`, `build(fort|depot)` — валидация всех условий с причинами отказа, списание золота, прогресс, отмена при потере гекса.
  *Приёмка:* сценарии на каждое условие отказа из `03-cities-buildings.md` (дистанция 3, население 59 %, нет золота, склад не на дороге, стройка в бою — отложить до 03).
- [x] **T6. Дороги.** Авто-дорога при основании города (A* по своей территории к ближайшему городу основной сети, 1,5 с/гекс); `findPath` для дорог.
- [x] **T7. `networkSystem`.** Компоненты связности, основная сеть, изоляция, размазывание пересчёта по игрокам (`tick % 10`).
  *Приёмка:* помощник сценарного DSL `setOwner` (не команда `sim`, см. `testing.md`) разрезает дорогу → город изолирован в течение ≤ 10 тиков; восстановление связи → снова основной.
- [x] **T8. `rebuildSupply`.** Путь, цена 15 × гексов без дороги, стройка, отмена при захвате гекса пути, отказ «нет пути по своей земле».
- [x] **T9. Запросы для UI:** `canFoundCity(hex)`, `cityInfo(cityId)` (все поля карточки города из `07-controls.md`), `rebuildSupplyPreview(cityId)`.
- [x] **T10. Локальный режим и отладочный вид.** `sim` в Web Worker, клиент получает `playerView` 10 раз/с. На `/dev/economy`: заливка территории, города простыми кругами, дороги линиями, изолированные — пунктиром, панель отладки гекса (pop/cap/рост), ползунок налога, кнопки стройки. Визуал временный, **не** финальный стиль.

## Вне объёма

Армии, бой, захват через бой, туман, финальная графика, боты.
