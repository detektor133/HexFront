# Этап 07 — Играбельная сборка и интерфейс

**Цель:** сборка по ссылке, в которую можно играть с телефона и которую можно дать людям на плейтест; интерфейс матча и меню — уровня продакшена (CR-009, решение владельца 2026-10-13). Большая оптимизация клиента и сервера перенесена в этап 09.

**Читать:** `art/ui.md`, `art/style-guide.md`, `gdd/07-controls.md` («Экраны MVP»), `gdd/08-match.md` («Победа», «Выбывание», «Пауза»), `architecture/rendering.md`, `docs/BUGS.md` (строки с «07/T»).
