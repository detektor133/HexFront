# Этап 03 — Армии, снабжение армий, бой, отступление

**Цель:** полная военная механика в `sim`: набор, движение, захват, снабжение армий и котлы, бой через организованность, отступление и капитуляция, артиллерия, прогноз боя, перенос столицы, победа.

**Читать:** `gdd/04-roads-supply.md`, `gdd/05-armies.md`, `gdd/06-combat.md`, `gdd/08-match.md`, `gdd/10-balance.md`.

## Задачи

- [x] **T1. Армии и набор.** `recruit` (люди из радиуса города, минимум 10 % лимита гекса, золото, очередь, время), лимит армий `4 + 2 × городов`, до 3 армий в гексе, появление в ближайшем свободном гексе. Содержание в `economySystem`, банкротство.
- [ ] **T2. Движение.** `findPath` для армий (A*, веса из `05-armies.md`, стабильный tie-break по `hexId`), `movementSystem` с прогрессом перехода, дороги, реки, ЗК ×2, низкое снабжение. Команды `move`, `setOrder(idle|hold|expand)`, `split`, `merge`.
- [ ] **T3. Захват пустых гексов**, эффекты захвата на население, артиллерия только по своим гексам, приказ `expand`.
- [ ] **T4. `supplySystem`.** Мультиисточниковый Dijkstra от узлов сети по своим гексам, `R = min(1, P/D)`, склады, `supplyLevel`, таймер истощения, истощение, котёл.
  *Приёмка:* сценарии «армия на дороге = 100 %», «4 гекса от дороги по равнине = 52 %», «окружена → 0 % → через 80 с (20 с льготы + 60 с истощения) ≤ 35 % солдат».
- [ ] **T5. `combatSystem`.** Формулы силы, флангов, рек, укреплений, городов, ополчения, гарнизонов; потери; org; исходы.
- [ ] **T6. Отступление и капитуляция** по `06-combat.md` (выбор гекса, −5 %, скорость, org 20, двойной урон при отступлении, капитуляция без гекса).
  *Приёмка:* все краевые случаи «Отступление» из `testing.md`.
- [ ] **T7. Артиллерия.** Обстрел, автоцель, фокус (`bombard`), бонус поддержки без стакания, бегство одиночной артиллерии.
- [ ] **T8. `forecastBattle`** по `PlayerView` (неизвестное снабжение = 100 %).
  *Приёмка:* на 50 сгенерированных сценариях прогноз «победа/поражение» совпадает с фактическим исходом ≥ 90 % при полной видимости.
- [ ] **T9. Столица, выбывание, победа, очки** (`capitalSystem`, `victorySystem`).
- [ ] **T10. Инварианты и golden.** Все инварианты из `testing.md` на случайных сценариях с армиями (fast-check, 500 прогонов в CI); golden-реплей «война двух игроков 5 минут».
- [ ] **T11. Бенчмарк.** Синтетический матч: 30 игроков, 4000 гексов, 200 армий, 20 боёв → `step` ≤ 3 мс среднее, ≤ 10 мс p99. Результат в отчёт.
- [ ] **T12. Отладочный вид армий** на `/dev/economy` → переименовать в `/dev/sandbox`: армии кружками с числом, приказы кликом, маркер боя, прогноз текстом. Временный визуал.

## Вне объёма

Автофронт и стрелки (этап 04), финальная графика, боты, сервер.

## Готово, когда

Можно в песочнице вручную сыграть против неподвижного соперника: захватить город, окружить армию и увидеть капитуляцию; все тесты и бенчмарк зелёные; отчёт.
