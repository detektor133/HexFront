# Этап 07 — Веб-запуск (soft launch)

**Цель:** игра опубликована на своём домене, CrazyGames и Яндекс Играх, реклама между матчами, аналитика удержания.

## Задачи

- [ ] **T1. `PlatformAdapter`**: единый интерфейс (`init`, `showMidgameAd`, `showRewardedAd`, `track`, `getUser`, `gameplayStart/Stop`) и реализации: `standalone`, `crazygames` (их SDK), `yandex` (Yandex Games SDK). Выбор по параметру сборки. Реклама — **только** между матчами и по кнопке rewarded.
- [ ] **T2. Локализация** ru/en: свой словарь JSON + функция `t()`, форматирование чисел по локали (`1,4к` / `1.4k`), язык от платформы/браузера.
- [ ] **T3. Аналитика**: события `match_start`, `match_end` (место, длительность), `tutorial_step`, `first_city_founded`, `ad_shown`; свой эндпоинт + события платформы. Дашборд D1/D7, длительность сессии.
- [ ] **T4. Производительность и размер**: первичная загрузка ≤ 10 МБ, время до меню ≤ 5 с на 4G, ленивые шрифты/карты.
- [ ] **T5. Требования порталов**: пауза и заглушение звука при рекламе, 16:9 адаптив, iframe, отсутствие внешних ссылок (CrazyGames), модерационный чек-лист Яндекса.
- [ ] **T6. Юридическое**: политика конфиденциальности, условия, возрастной рейтинг 12+, cookie-баннер для standalone (EU).
- [ ] **T7. RU-сервер**: деплой того же образа на российский VPS, выбор сервера клиентом по платформе/региону.

## Вне объёма

Аккаунты и магазин (этап 08).

## Критерии успеха soft launch (4 недели, решает владелец)

Средняя сессия ≥ 10 мин, D1 ≥ 20 %, D7 ≥ 7 %. Иначе — итерации геймплея, а не маркетинг.
