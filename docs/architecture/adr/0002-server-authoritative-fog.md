# ADR-0002: Авторитетный сервер с фильтрацией тумана

**Статус:** принято · 2026-09-23

## Контекст
Туман войны — часть геймплея. При lockstep каждый клиент знает всё состояние, maphack тривиален.

## Решение
Сервер симулирует матч и отправляет каждому игроку только его `PlayerView` дельтами на 10 Гц. Клиент шлёт только команды.

## Последствия
+ Туман нельзя обойти, клиент нельзя «подкрутить».
+ Команды низкочастотные (приказы), задержка 100–200 мс некритична — клиентская предикция не нужна.
− CPU и трафик сервера растут с числом игроков; обзор считается раз в секунду и размазан по тикам.
