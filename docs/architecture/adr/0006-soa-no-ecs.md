# ADR-0006: Структура состояния без ECS-библиотек

**Статус:** принято · 2026-09-23

## Решение
Гексы — структура массивов (typed arrays по полям). Города, армии, бои — массивы объектов, отсортированные по `id`. Системы — функции над этим состоянием.

## Зачем
Предсказуемый порядок (детерминизм), простая сериализация и хэширование, производительность на гексах, понятность агенту без изучения фреймворка.
