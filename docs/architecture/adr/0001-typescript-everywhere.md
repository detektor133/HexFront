# ADR-0001: TypeScript на сервере, клиенте и в симуляции

**Статус:** принято · 2026-09-23

## Контекст
Симуляция нужна в четырёх местах: авторитетный сервер, локальный режим клиента (Web Worker), боты, инструменты баланса. Разработка соло с AI-агентом.

## Решение
Весь код — TypeScript (strict). Симуляция — один пакет `packages/sim` без зависимостей.

## Альтернативы
- Python-бэкенд + TS-клиент: дублирование симуляции, расхождения, GIL на тик-лупе. Отклонено.
- Rust/WASM-ядро: быстрее, но второй язык и медленнее итерации. Вернуться, если `step` не уложится в бюджет производительности.

## Последствия
+ Один код симуляции везде, реплеи совместимы.
− Производительность JS: бюджет 3 мс/тик на матч; контролируется бенчмарком в CI.
