# ADR-0003: Fixed-point и детерминизм

**Статус:** принято · 2026-09-23

## Решение
Все величины состояния — целые (fixed-point ×1000). Нет float-математики, `Math.random`, времени. Стабильный порядок итераций. Хэш состояния для проверки.

## Зачем
Реплеи, golden-тесты, воспроизводимые баги, одинаковый результат локального режима и сервера, честный прогноз боя.

## Последствия
− Формулы с корнями/тригонометрией недоступны в `sim` (рендер может использовать float свободно).
+ Детерминизм проверяется автоматически и ловит ошибки AI-агента.
