# ADR-0004: Web-first, мобайл через Capacitor

**Статус:** принято · 2026-09-23

## Решение
Первичная платформа — браузер (свой сайт, CrazyGames, Яндекс Игры). Android/iOS — та же сборка в Capacitor на этапе 08.

## Зачем
.io-аудитория живёт в браузере и на порталах; порталы дают трафик без затрат на привлечение; выплаты с порталов доступны, сторы требуют юрлица/аккаунта третьей страны.

## Последствия
− Нативная производительность ниже; бюджет рендера: 60 fps на среднем Android 2022 года при 4000 гексах (кэш статических слоёв в текстуры).
