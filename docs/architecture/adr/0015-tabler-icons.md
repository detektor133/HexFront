# ADR 0015: Готовые иконки Tabler для интерфейса

**Статус:** принято · 2026-10-30

## Решение

Клиент использует официальную React-библиотеку `@tabler/icons-react` версии `^3.50.0` для готовых outline-иконок интерфейса. Пакет распространяется по лицензии MIT.

## Причина

Самодельные SVG-контуры в компонентах дублируют набор и требуют отдельной проверки геометрии. Один официальный набор сохраняет единый стиль и упрощает повторное использование значков.

## Последствия

Используются отдельные компоненты Tabler с размерами и цветами из `docs/art/ui.md` и `docs/art/tokens.json`. Тексты доступности остаются в системе локализации.
