# ADR 0013: DOM-среда для тестов клиента

**Статус:** принято · 2026-10-15

## Решение

Тесты клиента с суффиксом `.dom.test.tsx` запускаются в `jsdom` и используют `@testing-library/react`. Остальные тесты сохраняют текущую среду.

Поведение React-компонентов проверяется через DOM-рендер и Testing Library. `ResizeObserver`, `getBoundingClientRect`, `Worker` и холст Pixi подменяются в тестах, когда среда не предоставляет браузерную реализацию или реальные размеры.

## Причина

SSR-рендер не выполняет эффекты, клики и обновление состояния, поэтому он не подтверждает поведение экрана. `jsdom` ближе к браузеру и является стандартной средой для Testing Library; `happy-dom` для этой задачи не выбирается.
