# ADR-0005: PixiJS для карты, React для интерфейса

**Статус:** принято · 2026-09-23

## Решение
Карта рендерится PixiJS v8 (WebGL/WebGPU) императивно. React 19 — только DOM-оверлей: HUD, карточки, меню. Состояние UI — `useState`/`useReducer` + один внешний стор на `useSyncExternalStore` для данных матча.

## Отклонено
- React-обёртки над Pixi: лишняя реконсиляция на 10 Гц.
- Redux/Zustand/MobX: не нужны при одном источнике (снимок `PlayerView`).
- Canvas 2D: не вытянет 4000 гексов с анимацией на мобайле.

## Последствия
Статические слои (рельеф, территория) перерисовываются в RenderTexture только при изменениях; динамика (поток, фишки) — каждый кадр.
