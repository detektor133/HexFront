# Архитектура рендера карты

## Цель

Рендер карты не перестраивает слой, если его данные не изменились. Снимок без изменений территории не вызывает перестройку заливки, дорог, границ или тумана.

## Слои и инвалидирование

Карта состоит из независимых слоёв:

- территория — `Graphics` на чанк 16×16 гексов;
- границы — `Graphics` на чанк 16×16 гексов;
- туман — `Graphics` на чанк 16×16 гексов;
- дороги — отдельный слой, перестраиваемый только при изменении дорожной сети;
- метки и отряды — отдельные объекты с адресной инвалидизацией.

Изменение гекса инвалидирует только чанки, в которые входит этот гекс. Изменение границы инвалидирует чанки по обе стороны изменённой грани. Изменение тумана инвалидирует только затронутые чанки. Пустой набор изменений оставляет существующую геометрию и `Graphics` без вызова `clear`/перерисовки.

## Масштабирование

Геометрия карты имеет уровни детализации. Перестройка геометрии выполняется только при переходе между уровнями детализации. Изменение масштаба внутри одного уровня меняет трансформацию камеры, но не перестраивает геометрию слоёв.

Подписи и другие элементы, зависящие от уровня детализации, обновляются только при смене этого уровня или собственных данных объекта.

## Критерий производительности

Для сценария `gen`, seed 43, 30 ботов, скорость 5× и 10 минут матча клиент удерживает p95 кадра не выше 33 мс. Снимок без изменений территории не создаёт новой геометрии территории, дорог, границ или тумана.
