# Протокол клиент ↔ сервер

Транспорт: WebSocket (`wss://`), один сокет на игрока. Версия протокола в `packages/protocol/src/version.ts`, несовпадение → сервер отвечает `versionMismatch` и закрывает.

## Кодек

- Этап 06: JSON (простота отладки). Метрика трафика на игрока логируется.
- Если средний трафик > 4 КБ/с на игрока — переход на бинарный кодек (свой, на `DataView`, без зависимостей) через ADR.

## Клиент → сервер

```ts
type C2S =
  | { t: 'hello'; v: number; token?: string; nick: string; color?: string }
  | { t: 'cmd'; seq: number; cmd: Command }          // seq — для подтверждений
  | { t: 'ping'; at: number };
```

Rate limit: ≤ 20 команд/с на игрока; превышение — команды отбрасываются с `rejected: rateLimit`.

## Сервер → клиент

```ts
type S2C =
  | { t: 'welcome'; playerId: number; map: MapStatic; tickMs: number }
  | { t: 'snapshot'; tick: number; view: PlayerViewFull }        // при входе/реконнекте
  | { t: 'delta'; tick: number; d: ViewDelta }                     // каждый тик (10 Гц)
  | { t: 'ack'; seq: number } | { t: 'rejected'; seq: number; reason: string }
  | { t: 'event'; e: GameEvent }                                   // для ленты
  | { t: 'end'; results: MatchResult }
  | { t: 'pong'; at: number };
```

## Туман на сервере

- `ViewDelta` строится из `playerView` игрока: сервер хранит последний отправленный вид и шлёт разницу.
- Изменения владельцев гексов и городов — всем (политическая карта видна всегда).
- Армии, дороги, постройки — только внутри зоны обзора; при выходе из обзора — `forget`-сообщение с последним известным состоянием для «памяти».
- Прогноз боя на клиенте считается по `PlayerView` — клиент не знает больше, чем видит.

## Реконнект

- Токен сессии в `welcome`; при обрыве клиент переподключается с тем же токеном в течение 30 с → `snapshot`, управление возвращается.
- Через 30 с без соединения отряды и армии игрока переходят боту (`08-match.md`).

## Интерполяция на клиенте

Клиент рендерит с задержкой 100 мс и интерполирует позиции отрядов между тиками по прогрессу перехода (прогресс — часть `ViewDelta`).
