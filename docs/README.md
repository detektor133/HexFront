## Метки в документах

- `[ДИЗАЙН-РЕШЕНИЕ]` — решает владелец проекта, агент не трогает.
- `[ТЮНИНГ]` — число стартовое, будет меняться по результатам ботоматчей и плейтестов.
- `[MVP]` / `[ПОЗЖЕ]` — входит ли в первый релиз.
