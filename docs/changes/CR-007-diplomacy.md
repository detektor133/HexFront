# CR-007: Дипломатия — пакты, союзы, вероломство

**Статус:** черновик (решения — после плейтеста владельцем матча с ботами; значения по умолчанию ниже помечены `[ТЮНИНГ]`)
**Дата:** 2026-09-27

## Что меняем

**Сейчас:** режим MVP — каждый сам за себя (FFA), альянсы и команды — `[ПОЗЖЕ]` (`08-match.md`, DECISIONS 2026-09-23). Любой чужой игрок — враг; цвет «союзник» (`relation.ally`) есть в токенах, но не используется.

**После:** между любыми двумя игроками есть **отношение**: война (по умолчанию), пакт о ненападении, союз. Отношения меняются только кнопками, без чата: игрок предлагает «Пакт о ненападении на N мин» или «Союз», второй принимает или отклоняет. Договор можно разорвать с предупреждением (30 с) или внезапно — это **вероломство**; разрыв видит вся карта. У каждого игрока в списке игроков — счётчик нарушенных договоров и значок вероломства, только в пределах матча. Союз с ≥ 70 % городов побеждает вместе, места внутри коалиции — по вкладу. Боты учитывают доверие при договорах.

### Отношения

| Отношение | Что значит |
| --- | --- |
| Война | Как сейчас: вход в гекс = захват или атака, граница с ним — граница фронта |
| Пакт о ненападении на 3 / 5 / 10 мин `[ТЮНИНГ]` | Атаковать и входить в гексы друг друга нельзя; граница — не фронт; по истечении срока — снова война (сразу или с предупреждением — открытый вопрос 2) |
| Союз | Общий обзор; снабжение и проход по дорогам союзника; атаковать и захватывать гексы друг друга нельзя; фронта между союзниками нет |

### Договоры

- Предложение — кнопкой в карточке игрока (или по тапу на его территорию): «Пакт» (срок N мин выбирается рядом цифрами) и «Союз» — по правилу `art/ui.md` «одна иконка — одно слово». У получателя — событие в ленте с кнопками «Принять» / «Отклонить» и таймаутом.
- Разрыв:
  - **с предупреждением** — через 30 с отношение становится «война»; вся карта видит событие «X разрывает договор с Y через 30 с»; отряды в гексах бывшего союзника за эти 30 с должны уйти к себе `[ТЮНИНГ]`;
  - **внезапно** — сразу «война»; событие «X вероломно нарушил договор с Y»; +1 к счётчику нарушений X, значок вероломства. Отряды в гексах бывшего союзника сразу оказываются на вражеской земле: бой, возможный котёл — это и есть цена предательства.
- Доверие — только в рамках матча: счётчик нарушенных договоров и значок вероломства в списке игроков. Между матчами не сохраняется.

### Победа коалиции

- Союз, чьи участники вместе контролируют ≥ 70 % городов карты 60 с подряд (`08-match.md`, «Победа»), побеждает вместе.
- Места внутри коалиции — по вкладу: города × 10 + гексы на момент победы, без солдат `[ТЮНИНГ]`.

## Зачем

Владелец: FFA на 20–40 игроков без дипломатии быстро превращается в войну всех со всеми у каждой границы; договоры дают выбор, с кем воевать, а вероломство и доверие — социальную глубину без чата (чат на портале — модерация и токсичность). Отношения — основа для решений commander (CR-006): «мир/союз — фронта нет, никогда не атаковать».

## Тесты

- Отношения: пакт запрещает `attack`/`move` в гексы стороны (отказ с причиной); союз — проход без захвата, снабжение по дорогам союзника, общий обзор в `playerView`.
- Разрыв с предупреждением — «война» ровно через 30 с; внезапный — сразу, +1 нарушение, событие всем.
- Истечение пакта.
- Победа коалиции при ≥ 70 % городов у союза 60 с; места по очкам (города × 10 + гексы) на момент победы.
- Разрыв с предупреждением: отряд, не ушедший из гексов бывшего союзника за 30 с, оказывается на вражеской земле; при вероломстве — сразу.
- Инварианты: отношение симметрично; нет фронта по грани с союзником.
- Golden-хэши изменятся (новое состояние `relations`).

## Риски и откат

- Затрагивает почти все системы sim (снабжение, движение, захват, бой, победа, туман) — большой объём, риск регрессий; нужен полный набор сценариев до применения.
- Коалиция из многих игроков может завершать матчи слишком рано или делать их скучными — метрики баланса этапа 05.
- Без чата договоры могут не читаться: нужен плейтест интерфейса предложений.
- Откат — `git revert` коммитов CR-007; до применения отношений commander (CR-006) работает с «все — война».
