# CR-003: Линии по граням, фронт по любой границе, панель и фишка как в HoI4

**Статус:** принят владельцем 2026-09-26 (прямое поручение в чате) и применён; код — 04/T2b
**Дата:** 2026-09-26

## Что не так сейчас (замечания владельца к 04/T2a)

1. Интерфейс не похож на HoI4.
2. Линия фронта ставится только против соседа; нельзя нарисовать участок по ничейной земле. Линия должна рисоваться **по граням** границы.
3. Линия наступления вводится отдельными тапами по центрам гексов; на телефоне неудобно. Она тоже должна рисоваться по граням.
4. Цвет армии — только тонкое кольцо; нужна сплошная полоса. Организацию не видно (полоска под фишкой), не видно, что армия страдает от снабжения.

## Что меняем

1. **Участок фронта** — цепочка своих пограничных гексов: граница с врагом **или ничьей землёй**. Рисуется по граням: палец (ЛКМ с зажатием) ведёт линию, она прилипает к ближайшей грани своей границы; тап по грани добавляет точку, между точками линия достраивается по граням границы. Тап по грани на границе с врагом — весь **непрерывный** кусок границы с ним (оторванные куски той же границы не берутся). Когда граница сдвигается, каждый гекс участка переносится на ближайший гекс новой границы — фронт «едет» за границей.
   - Команда `assignFront(armyId, points)`; вместо `enemyId`/`section`.
   - Деление общего фронта между армиями пропорционально солдатам **убрано**: у каждой армии свой участок.
2. **Линия наступления** рисуется так же — пальцем или тапами по граням. Из двух гексов грани в линию входит тот, что ближе к фронту армии; на карте линия — внешняя кромка этих гексов с наконечниками вперёд.
3. **Режим рисования** на телефоне: один палец рисует, два пальца двигают и зумят карту; мышь — ЛКМ рисует, колесо зумит, ПКМ-перетаскивание двигает. Кнопки «Готово», «Заново», «Отмена»; ПКМ или долгий тап убирает последнюю точку.
4. **Панель армий как в HoI4**: ряд карточек армий внизу экрана (полоса цвета армии во всю высоту, название, солдаты, полоски организации и снабжения, «Истощение: N отр.» красным, план); тап по карточке выбирает армию и её отряды, над рядом — приказы иконками: Фронт, Наступление (только с фронтом), Оборона, Стоп, Снять план, Держать, Экспансия, Расформировать. Резерв, «Автопополнение» и «Новая армия» — последней карточкой.
5. **Фишка**: цвет армии — сплошной полосой/заливкой, не кольцом; организация — внутри фишки; снабжение — столбик и треугольник (жёлтый — ниже 50 %, красный — идёт истощение). Три варианта на выбор владельца, переключатель в песочнице: «HoI4», «Батарейка», «Значок» (`units.md`). После выбора лишние убираются.
6. В снимок отряда добавлен флаг `starving` — отряд прямо сейчас теряет солдат от истощения.
