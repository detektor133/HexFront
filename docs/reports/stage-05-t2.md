# Отчёт 05/T2

## Трассировка

| Критерий | Подтверждение |
| --- | --- |
| Natural Earth во временной папке | `packages/mapgen/import/europe.ts` скачивает четыре ZIP из `naciscdn.org` в `mkdtemp`, распаковывает через `tar` и удаляет каталог после генерации; исходные данные не коммитятся |
| Границы и проекция | Скрипт использует границы `−11…40°`, `35…71°` и собственную формулу ETRS89-LAEA с идентификатором `EPSG:3035`; размер сетки вычисляется из спроецированного отношения сторон и площади на 30 игроков |
| Горы, холмы и биомы | SHP `ne_10m_geography_regions_polys` фильтруется по `Range/mtn`; соседнее кольцо получает холмы; остальные гексы суши получают процедурные пустыню/лес/равнину |
| Города, спавны, дороги и формат | `packages/mapgen/maps/europe.json` проходит `loadMap`, содержит 30 спавнов, города из `CITY_NAMES`, дороги и `riverEdges`; профильный тест 2/2 |
