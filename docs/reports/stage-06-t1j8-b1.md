# Отчёт 06/T1j8-Б1

## Решение

- Экзамен больше не использует место кандидата и fitness обучения.
- Экзаменационная формула считает победу, прогресс лидера по городам и максимальные штрафы по всем игрокам.
- Экзаменационные матчи запускаются через worker pool с тем же параметром `--workers`, что и матчи обучения.
- Отчёт поколения записывает fitness, победу, тик окончания, города лидера и нужное число городов, а также максимальные штрафы.

## Проверки

- `pnpm exec vitest run tools/evolve/src/index.test.ts` — 11/11.
- Табличный тест `calculateExamFitness` подтверждает отсутствие места, прогресс 0/половина/нужное число/выше нужного и штрафы по общей функции обучения.
- Существующий тест запуска `runEvolution` с `workers=1` и `workers=4` подтверждает одинаковые веса и отчёты; после изменения экзамен также выполняется через этот путь.
- `pnpm verify --changed` — `verify: OK (45 с)`.
- `pnpm verify` — `verify: OK (301 с)`.

## Исправление возврата на ревью

- `tools/evolve/src/index.test.ts:122-158` не проверяет реальный путь `evaluateExamMatch`/`evaluateExam`, независимость оценки самоигры от слота и максимум метрик по разным игрокам.
- `tools/evolve/src/index.test.ts:162-230` не сравнивает экзаменационные оценки и отчёты при `workers=1` и `workers=4`; сравниваются только итоговые веса.

- Тест `runEvolution` сравнивает экзаменационные оценки и строки отчётов поколений 0 и 2 при `workers=1` и `workers=4`.
