# Отчёт 06/T1d — путь ботов в commander

## Сделано

- Для ботов резерв и новые отряды направляются в армию с `startWanted` или активным наступлением; без такой цели сохраняется выбор самой слабой армии.
- Малый однотипный отряд без приказа, боя и отступления идёт к ближайшему однотипному отряду своей армии в радиусе `BOT_MERGE_RADIUS`; после прибытия commander выдаёт `merge`.
- `BotLevel` вынесен в отдельный типовой модуль, чтобы убрать цикл `brain → run → brain` в dependency-cruiser.
- Поведение людей в commander не изменено; golden-проверки прошли.
