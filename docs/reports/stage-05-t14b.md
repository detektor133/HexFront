# Отчёт 05/T14b — инкрементальные снабжение, сети и изоляция

## Сделано

- Добавлен кэш производных данных по владельцу: сети пересчитываются только после изменения
  территории, дороги или города.
- Карты потерь снабжения кэшируются отдельно для каждого владельца.
- Расстояния от сети до гексов кэшируются отдельно для каждой сети и сбрасываются только при
  изменении снабжения владельца.
- Устаревшие записи `supplyRatios` удаляются после распада сети.
- Добавлен тест эквивалентности на 3000 тиках с захватами, движением и боями.

| Проверка | Результат |
| --- | --- |
| Целевые тесты снабжения и сетей | 25 тестов, зелёный |

| `pnpm verify` | `verify: OK (261 с)` |
| Full-match 30/100 ботов, минуты 1–5 | ожидает `$accept` |

сравнить таблицу `step` и карты с колонкой «факт» отчёта предыдущей принятой задачи T14.
