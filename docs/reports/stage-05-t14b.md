# Отчёт 05/T14b — инкрементальные снабжение, сети и изоляция

## Сделано

- Добавлен кэш производных данных по владельцу: сети пересчитываются только после изменения
  территории, дороги или города.
- Карты потерь снабжения кэшируются отдельно для каждого владельца.
- Расстояния от сети до гексов кэшируются отдельно для каждой сети и сбрасываются только при
  изменении снабжения владельца.
- Устаревшие записи `supplyRatios` удаляются после распада сети.
- Добавлен тест эквивалентности на 3000 тиках с захватами, движением и боями.

## Исправление 05/T14b-Б1

- Проверяемое состояние больше не пересчитывается полным путём: эталон клонируется до тика,
  получает команды и системы до снабжения, затем полный пересчёт выполняется только на клоне.
- После каждого тика сравниваются только игроки текущей фазы
  `p.id % NETWORK_RECALC_TICKS === tick % NETWORK_RECALC_TICKS`; проверяются сети, стабильные
  гексы `hexes.network`, `supplyRatios`, `supplyLevel` и `encircled`.
- Покрыты war-script, склад и форт, достройка дороги, основание города, перенос столицы,
  `hexSupplyEff` между захватом и пересчётом сети и gen seed 43 на 30 игроках за 1000 тиков.
- При изменении `hexes.network` инвалидируется кэш снабжения владельца; очистка `supplyRatios`
  ограничена сетями этого владельца. Golden-хэши не менялись.
