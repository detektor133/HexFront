# Отчёт о возвратах ревью 07/T17s

Материал перенесён из блока этапа после решения владельца 2026-10-18. Старые возвраты описывали предыдущую ширину 238 px, неполные проверки сортировки и геометрии, расчёт по первым пяти игрокам, неверную высоту с границами, сравнение лидерборда с самим собой при налоге, скрытие на тесном viewport, непроверенные крайние значения счёта, `min-width: 0` и абсолютное позиционирование.

Эти замечания относятся к отменённым ПК-требованиям и заменены актуальным блоком T17s: постоянно видимый компактный топ-5, источник `view.ranking[].score`, сортировка по очкам и `playerId`, место по очкам, обрезание только ника, отсутствие прокрутки и сохранение остальных панелей.
