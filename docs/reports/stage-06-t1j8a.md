# Отчёт 06/T1j8a

1. `tools/evolve/src/index.ts:createMatchup` формирует один набор из пяти соперников на поколение: сначала используются последние записи зала славы, недостающие позиции заполняются стартовыми весами. Все особи получают одинаковый слот кандидата и одинаковые слоты соперников.
