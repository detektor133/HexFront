# GDD 04 — Дороги и снабжение

Снабжение — центральная механика и центральный визуальный элемент («линии метро»).

## Дороги

- Дорога — булево свойство гекса. Два соседних дорожных гекса соединены.
- **Исходные дороги** генерирует карта между нейтральными городами и столицами.
- **Авто-дорога**: при основании города бесплатно строится дорога по кратчайшему пути (A*, веса местности) **только по своей территории** до ближайшего города своей основной сети. Строится по 1 гексу каждые 1,5 с (визуально «прорисовывается»). Если пути нет — город основан изолированным.
- Дороги не уничтожаются; принадлежат владельцу гекса.

## Сети снабжения

Каждые **10 тиков (1 с)** пересчитываются сети игрока:

1. Узлы — свои гексы с дорогой или городом.
2. Сеть — компонента связности узлов через соседство (только свои гексы; враждебный гекс разрывает связь — это и есть «путь не проходит через вражеский гекс»).
3. **Основная сеть** — содержащая столицу. Остальные — **изолированные**.

Изолированная сеть: золото, снабжение ×0,5, рост населения ×0,75. Её города показываются с пунктирной линией и значком разрыва. Налог с обычных гексов территории режется ×0,5, только если все свои города в радиусе 2 от гекса изолированы (правило — `02-economy.md`, «Золото»).

## Снабжение армий

```
P(сеть) = Σ снабжение городов сети (изолированной ×0,5)
D(сеть) = Σ soldiers × supplyPerSoldier(type) армий, приписанных к сети
R(сеть) = min(1, P / D)

eff(армия) = max(0, 1 − потери пути)   // путь от ближайшего узла сети до гекса армии
  потери пути = Σ по гексам вне дорог offroadLoss(terrain)   // внутри сети по дорогам снабжение идёт без потерь
  offroadLoss: равнина 12 %, лес/холмы/пустыня 15 %, горы 25 %; в радиусе 3 от склада — вдвое меньше

supplyLevel(армия) = R(сеть) × eff(армия)
```

- Армия приписывается к сети, дающей ей **максимальный** `supplyLevel`.
- Путь от узла до армии ищется только по своим гексам (Dijkstra с мультиисточником от всех узлов, стоимость = offroadLoss). Армия на вражеском/нейтральном гексе (во время наступления) получает путь через последний свой гекс + потери за этот гекс.
- Армии без пути: `supplyLevel = 0` → котёл.

## Последствия снабжения

| supplyLevel | Эффект |
| --- | --- |
| 100 % | Норма |
| < 100 % | Бой ×(0,5 + 0,5 × s) |
| < 50 % дольше 20 с | Истощение: потери `2 %/с × (1 − s / 0,5)` солдат; регенерация организованности 0; скорость ×0,75 |
| 0 % | После 20 с — истощение 2 %/с: окружённая армия теряет ~70 % за следующую минуту |

## Перестройка линий снабжения (кнопка в карточке города)

Если город **изолирован** (его сеть не содержит столицу):

- В карточке города появляется кнопка **«Перестроить снабжение»**.
- Ищется кратчайший путь (A*, веса местности, только свои гексы) от города до любого узла основной сети.
- Цена: **15 золота × длина пути** (гексов без дороги). Время: 1,5 с на гекс, прорисовывается как авто-дорога.
- Если пути по своей территории нет — кнопка неактивна с текстом «Город окружён — нет пути по своей земле».
- Во время строительства путь подсвечен пунктиром-«стройкой»; захват гекса пути отменяет стройку (оплаченное не возвращается).

Это решение для ситуаций «враг перерезал дорогу, но у меня есть обходная территория». Автоматически дороги после разреза **не** восстанавливаются — это осознанное решение игрока за деньги.

## Видимость линий

Линии снабжения (дороги с анимацией потока) видны только в зоне обзора (см. `08-match.md`). Вне обзора — последнее известное состояние, приглушённое.
