# GDD 08 — Матч, туман войны, победа

## Параметры

| Параметр | Значение |
| --- | --- |
| Игроков | 20–40, пустые места — боты (`09-bots.md`) |
| Карта | ~120 проходимых гексов на игрока |
| Длительность | цель 18–22 мин; жёсткого таймера нет — матч идёт до победы |
| Режим MVP | Каждый сам за себя (FFA). Альянсы и команды — `[ПОЗЖЕ]` |
| Туман | Параметр матча `fog`: по умолчанию включён; значение хранится в состоянии и входит в хэш |

Лимит обычного матча остаётся 20–40 игроков. Расширение `packages/mapgen` до `MAPGEN_MAX_PLAYERS` нужно для генерации карт и производительных бенчмарков, а не для изменения состава обычного матча.

## Старт

- **3 гекса**: столица уровня 1 + 2 соседних гекса. Соседи выбираются детерминированно: проходимые, с наибольшим лимитом населения, при равенстве — по порядку направлений `SE, NE, N, NW, SW, S` (индексы 0–5 из `01-map.md`). `[ДИЗАЙН-РЕШЕНИЕ 2026-09-23]`
- Игроки распределяются по спавнам карты случайно: спавны перемешиваются seeded PRNG из потока `RNG_STREAM.spawns` (`fork(seed, RNG_STREAM.spawns)`), игрок `i` получает `i`-й спавн после перемешивания. Порядок спавнов в файле карты не даёт преимущества. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-24]`
- Население: столица 200, два стартовых гекса по 40.
- 200 золота, налог 20 %.
- Два отряда пехоты по 100, org 100, без приказа (`idle`), оба в «Армии 1» с автокомандованием (auto по настройке игрока): армия сразу занимает ничью землю (`07-controls.md`, «Автокомандование»). `[ДИЗАЙН-РЕШЕНИЕ 2026-09-27]` Первый приказ (ничья земля, фронт) достаётся этой же «Армии 1», новая армия не создаётся.
- Вся остальная земля — нейтральная, с начальным населением 20 % лимита (захват сразу даёт налоговую базу).
- Отсчёт 5 с перед стартом («Подготовка»), в это время можно выбрать направления.

## Туман войны

| Что | Видимость |
| --- | --- |
| Рельеф, реки, особые гексы | Всегда |
| Владельцы всех гексов (политическая карта), границы | Всегда |
| Города (владелец, уровень) | Всегда |
| Вражеские отряды | Только в зоне обзора |
| Дороги и снабжение (своя сеть, изоляция, разрывы) | Только в зоне обзора; вне — последнее известное, приглушённо |
| Постройки (укрепления, склады), стройки | Только в зоне обзора |
| Население гексов, налог, золото врагов | Никогда |

**Зона обзора** = своя территория + 2 гекса, + 3 гекса вокруг своих отрядов, + 3 вокруг своих городов. Пересчитывается раз в секунду. На сервере — источник истины (клиент не получает невидимое).

Чужая казна, налог и фактический налог в `playerView` всегда 0: это закрытые данные игрока (в сетевом матче они не должны уходить другим клиентам). Свои значения видны полностью. `[ДИЗАЙН-РЕШЕНИЕ 2026-11-10]`

При `fog: false` ограничение обзора отключено: `playerView` отдаёт полный снимок, как до T3, без скрытия и памяти тумана. В песочнице `/dev/sandbox` переключатель «Туман» меняет этот параметр матча.

## Победа

Первое выполненное:
1. **Захват всех городов карты** игроком или его коалицией — победа сразу, без отсчёта.
2. **Контроль ≥ 70 % всех городов**, удерживаемый 60 с непрерывно (отсчёт показывается всем); города союзников считаются вместе.
3. Все остальные игроки выбыли.
4. **Коалиция:** все живые игроки — союзники друг другу; побеждают вместе (событие `matchWon` с `allies`).

Таймера матча нет (решение владельца 2026-11-05): пока игра идёт и игрок играет, матч не обрывается. Победа фиксируется в состоянии (`winner`) один раз; симуляция не замораживается — матч останавливает сервер. «Все остальные выбыли» проверяется только при двух и более игроках. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-25]`

## Выбывание

- Нет городов и нет отрядов → выбыл сразу.
- Нет городов, но есть отряды → 60 с на захват любого города, иначе выбыл.
- Территория выбывшего становится нейтральной (без гарнизонов), его отряды и армии распускаются.
- Выбывший может смотреть матч (наблюдатель) или выйти. — карточка «Вы выбыли · место N» с кнопками «Смотреть» и «В меню» (`art/ui.md`).
  Онлайн «Смотреть» открывает интерфейс лучшего живого игрока, стрелки ◀ ▶ листают живых игроков по таблице; приказов в этом виде нет, сервер их не исполняет. Живой игрок смотреть чужими глазами не может.

## Пауза

В локальном матче против ботов игрок может поставить паузу; скрытая вкладка ставит паузу сама. В матче с людьми (этап 09) паузы нет. `[ДИЗАЙН-РЕШЕНИЕ 2026-10-13]`

## Дипломатия `[ДИЗАЙН-РЕШЕНИЕ 2026-11-03]` (CR-007, первая версия)

- Между любыми двумя игроками есть отношение: **мир** (по умолчанию), **война**, **пакт о ненападении**, **союз**. Матч без дипломатии (`createMatch` без `diplomacy`) — все в войне, как раньше.
- **Интерфейс:** клик по чужой территории или столице открывает карточку с блоком дипломатии — отношение, число нарушений договоров, ответ на предложение (принять/отклонить) и маленькие кнопки: война; в войне — мир; в мире — пакт и союз; разрыв договора. Под названием государства на карте — значок отношения (война, пакт, союз); при мире значка нет; входящее предложение показано значком договора цвета предупреждения.
- **Мир, пакт, союз:** нападать нельзя; отряды не входят в гексы, города и земли друг друга (союзник пропускает без захвата). Фронт и наступление идут только против тех, с кем война; ничья земля и нейтральные города — как прежде.
- **Война** объявляется командой `declareWar` **сразу, без предупреждения**; ответ — бой по обычным правилам.
- **Договоры** — `proposeTreaty` (`peace`, `pact` или `alliance`) → адресат отвечает `answerTreaty`; предложение живёт `OFFER_TTL_TICKS` = 300 тиков (30 с). Из войны можно предложить только **мир** (`peace`: возвращает обычный мир, не пакт); пакт — только из мира, союз — из мира или пакта. При заключении атаки друг на друга снимаются.
- **Договоры — не гарантия, а слово.** Их можно нарушить: `breakTreaty` (в мир) или `declareWar` на партнёра по пакту или союзу — это **нарушение**, у нарушителя +1 в счётчике `violations`. Счётчик виден всем игрокам в списке и учитывается ботами при решении принять договор.
- События: `warDeclared`, `treatyOffered`, `treatyMade`, `treatyBroken` — для ленты и ботов.
- **Союзники делят обзор:** туман над территорией и отрядами союзника снимается, а союз рвётся — возвращается. Приказ своим отрядам на гекс союзника — обычное движение (не атака). Боты не считают союзников, пакт и мир угрозой и целью наступления.
- Снабжение по дорогам союзника и победа коалиции — позже.

### Оборонительный пакт и альянс `[ДИЗАЙН-РЕШЕНИЕ 2026-11-10]`
Прежний «союз» разделён на два договора; пакт о ненападении остаётся.

- **Оборонительный пакт** (`defense`, пара стран; из мира или пакта). Когда на одного из пары объявляют войну, второй получает в ленте запрос «союзник просит помощи: вступить в войну?» (`AID_TTL_TICKS` = 300 тиков). Ответ `answerAid`: **да** — война агрессору без нарушения договоров; на время этой войны туман над союзником снят и отряды проходят по его земле; когда война кончается (мир, выбывание), отряды на земле союзника сами возвращаются на свою территорию. **Нет** или нет ответа — пакт аннулируется (возвращается мир, без нарушения).
- **Альянс** (`alliance`, любое число стран). Члены — клика: каждый союзник каждого. Общий туман и проход, победа коалицией. **Война одному члену — война всем**: когда на члена объявлена война, остальные члены сразу воюют с агрессором (и члены альянса агрессора — с атакованным); долг альянса сильнее пакта о ненападении и оборонительного пакта с противником — они рвутся без нарушения; в союзе с самим противником (общий член) война не начинается. Так же автоматически вступают в войну и при наступательной, а не только оборонительной войне альянса. Объявивший войну члену своего же альянса — предатель: альянс против него, нарушение +1.
- **Кворум — большинство** (`yes × 2 > избирателей`). Вход в альянс: предложение и согласие сторон как обычно; если у какой-то стороны уже есть альянс, члены обеих групп голосуют (`castVote`; предлагающий и согласившийся голосуют «за» сами; `VOTE_TTL_TICKS` = 600 тиков, не решили — отказ), принятый входит в альянс со всеми. Мир: если кто-то из сторон в альянсе, мир — тоже голосование, но каждая сторона с альянсом решает большинством **своих** членов отдельно (враг за наш мир не голосует, а ответ одного члена альянса не решает за остальных); приняли обе стороны — **общий мир** для всех воюющих пар (сепаратного мира внутри альянса нет). Без альянсов у сторон — как раньше, ответом адресата.
- **Исключение члена** — `proposeExpel` (альянс не меньше чем из троих, нельзя исключать себя): голосуют остальные члены без исключаемого, предлагающий уже «за»; больше половины — исключённый уходит в мир со всеми членами без нарушения; одно голосование об исключении одного игрока за раз.
- **Итог голосования виден.** Законченное голосование (принято, отклонено или не решено в срок) остаётся в снимке `RESULT_TTL_TICKS` = 300 тиков с ответами каждого, чтобы быстрый ответ ботов не прятал исход; голосования видят избиратели, инициатор и цель (цель и инициатор без права голоса только смотрят).
- **Выход из альянса** — `breakTreaty`: игрок выходит из альянса целиком (мир со всеми членами), нарушение +1.
- События и снимок: в `DiplomacyView` — `aidCalls` (кому мне помочь) и `votes` (голосования, где я ещё не ответил); команды `answerAid` и `castVote`.
- Боты отвечают в голосовании не раньше чем через `BOT_VOTE_DELAY_TICKS` = 30 тиков (плюс разброс по игроку до 30), чтобы человек успел увидеть ход. За исключение голосуют, если у исключаемого нарушений больше, чем у них.
- Боты: пакт предлагают как раньше; на запрос помощи вступают, если агрессор не сильнее; в голосованиях за договор голосуют «за», если нарушений у инициатора не больше своих + 1; мир — «за».
