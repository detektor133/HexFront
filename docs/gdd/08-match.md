# GDD 08 — Матч, туман войны, победа

## Параметры

| Параметр | Значение |
| --- | --- |
| Игроков | 20–40, пустые места — боты (`09-bots.md`) |
| Карта | ~120 проходимых гексов на игрока |
| Длительность | цель 18–22 мин, жёсткий таймер 25:00 |
| Режим MVP | Каждый сам за себя (FFA). Альянсы и команды — `[ПОЗЖЕ]` |

## Старт

- **3 гекса**: столица уровня 1 + 2 соседних гекса. Соседи выбираются детерминированно: проходимые, с наибольшим лимитом населения, при равенстве — по порядку направлений `SE, NE, N, NW, SW, S` (индексы 0–5 из `01-map.md`). `[ДИЗАЙН-РЕШЕНИЕ 2026-09-23]`
- Игроки распределяются по спавнам карты случайно: спавны перемешиваются seeded PRNG из потока `RNG_STREAM.spawns` (`fork(seed, RNG_STREAM.spawns)`), игрок `i` получает `i`-й спавн после перемешивания. Порядок спавнов в файле карты не даёт преимущества. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-24]`
- Население: столица 200, два стартовых гекса по 40.
- 200 золота, налог 20 %.
- Две армии пехоты по 100, org 100, приказ `expand`.
- Вся остальная земля — нейтральная, с начальным населением 20 % лимита (захват сразу даёт налоговую базу).
- Отсчёт 5 с перед стартом («Подготовка»), в это время можно выбрать направления.

## Туман войны

| Что | Видимость |
| --- | --- |
| Рельеф, реки, особые гексы | Всегда |
| Владельцы всех гексов (политическая карта), границы | Всегда |
| Города (владелец, уровень) | Всегда |
| Вражеские армии | Только в зоне обзора |
| Дороги и линии снабжения (поток, разрывы) | Только в зоне обзора; вне — последнее известное, приглушённо |
| Постройки (укрепления, склады), стройки | Только в зоне обзора |
| Население гексов, налог, золото врагов | Никогда |

**Зона обзора** = своя территория + 2 гекса, + 3 гекса вокруг своих армий, + 3 вокруг своих городов. Пересчитывается раз в секунду. На сервере — источник истины (клиент не получает невидимое).

## Победа

Первое выполненное:
1. **Контроль ≥ 70 % всех городов карты**, удерживаемый 60 с непрерывно (отсчёт показывается всем).
2. Все остальные игроки выбыли.
3. Таймер 25:00 → победа по очкам: `города × 10 + гексы × 1 + солдаты / 100`.

## Выбывание

- Нет городов и нет армий → выбыл сразу.
- Нет городов, но есть армии → 60 с на захват любого города, иначе выбыл.
- Территория выбывшего становится нейтральной (без гарнизонов), его армии распускаются.
- Выбывший может смотреть матч (наблюдатель) или выйти.

## Очки и места

Живой рейтинг по очкам в HUD («#4 из 30»). Места выбывших — по порядку выбывания.

## Отключение игрока

Армии переходят под управление бота через 30 с отсутствия; при возвращении — управление возвращается.
