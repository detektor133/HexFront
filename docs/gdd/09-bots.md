# GDD 09 — Боты

Боты обязательны: заполняют лобби, делают первые матчи новичков интересными, служат инструментом баланса (headless-матчи).

## Архитектура

- Бот — чистая функция от состояния матча и общего контекста тика → `Command[]`, вызывается раз в `BOT_THINK_TICKS` (со смещением по id, чтобы не все в один тик). Отдельной памяти у бота нет: его задачи — планы армий в состоянии матча (раздел «Utility AI»).
- Бот видит **только** то, что видел бы игрок (тот же туман): вражеские отряды — только в его зоне обзора. Никакого читерства.
- Бот выдаёт **те же команды**, что клиент игрока. Отдельных «бот-API» в `sim` нет.
- Случайность — seeded PRNG бота (сид = сид матча + id игрока).
- Уровень бота (`easy` или `medium`) передаётся необязательным массивом по id игрока рядом с массивом `bots` в `commanderCommands` и `botCommands`; отсутствующий уровень означает `medium`. Уровень не входит в `MatchState` и его хэш.
- **Военная часть бота — commander** (`07-controls.md`, «Автокомандование»): армии бота — с auto, отдельных приказов бот им не отдаёт. Utility AI ниже — экономика и крупные решения (налог, стройки, набор, дорога, когда нажать ▶ «Начать» на армии).

## Utility AI

- Решение бота — раз в `BOT_THINK_TICKS` (easy — `BOT_EASY_THINK_TICKS`), только в его ход: снимок (`bots/snapshot.ts`) → варианты команд из реестра → признаки → оценка по весам → команды.
- Варианты команд — реестр `bots/options/index.ts`; варианты и эффекты каждого вида команды — в своём файле `bots/options/<вид>.ts`. Вариант — команда, группа и эффекты: изменение показателей игрока относительно их текущего значения (цена — доля золота). Типы юнитов и постройки берутся из определений `balance.ts` (таблицы `ByUnit`, `BUILDING_DEFS`). Новая механика добавляется новым файлом в `bots/options` и строкой регистрации; мозг бота не меняется. Новый тип юнита или постройки не требует ни одной строки кода бота.
- Признаки строятся автоматически из ключей эффектов: каждый контекст, каждый эффект и эффект × каждый контекст. Контексты: угроза = max по врагам `theirs / (mine + theirs)`, запас золота = золото / доход (секунды дохода), доля своих граничных гексов у ничьей земли. Признака нет в весах — его вес 0.
- Оценка варианта = Σ `вес × признак`, целые числа. В каждой группе берётся один вариант с наибольшей оценкой > 0; выбранные исполняются по убыванию оценки, траты — пока хватает золота. Лимита числа действий, резерва золота и других ручных порогов нет: налог, ▶/■, набор и стройки решают веса.
- Веса — данные `bots/weights.json` (средний) и `bots/weights-easy.json` (лёгкий), подбираются офлайн-обучением `tools/evolve` (ADR 0010); вручную не правятся. В весах лежат и параметры пути ботов в commander: порог и радиус слияния малых отрядов. Обучение в матче не ведётся: детерминизм (ADR 0003) и бюджет тика 15 мс.
- Числа ботов, которые не решают «что делать»: `BOT_THINK_TICKS`, `BOT_EASY_THINK_TICKS` (как часто бот думает) и `BOT_LINE_MAX_DEPTH` (предел вычислений линии наступления).
- Армия экспансии создаётся по прежнему правилу. Автопополнение бот включает.
- **Путь ботов в commander** (только армии ботов; армии людей и игроков без бота — без изменений, правило `07-controls.md` «лишние отряды — в самую слабую армию» для них остаётся): резерв и новые отряды — в армию цели (`startWanted` или активное наступление), если её нет — по старому правилу; свой отряд меньше порога слияния из весов (`commander.mergeBelowSoldiers`), не в бою и не отступающий, идёт в гекс ближайшего однотипного отряда своей армии в радиусе слияния из весов (`commander.mergeRadius`) (в гексе меньше 3 отрядов) и там сливается. Команды идут с `source: 'auto'` и auto не выключают.
- Уровни различаются только весами и частотой решения (раздел «Уровни»).

## Уровни

Уровни — параметры utility AI и commander.

| Уровень | Отличия |
| --- | --- |
| Лёгкий | Веса `weights-easy.json` — лучшая особь раннего поколения обучения; решение раз в `BOT_EASY_THINK_TICKS`; отдельных правил нет |
| Средний (по умолчанию) | Веса `weights.json` — лучшая особь последнего поколения; реакция 1 с |
| Сложный `[ПОЗЖЕ]` | Целенаправленно режет дороги, ищет котлы |

Новичку в первых 3 матчах — больше лёгких ботов по соседству.
