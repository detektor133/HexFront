# GDD 09 — Боты

Боты обязательны: заполняют лобби, делают первые матчи новичков интересными, служат инструментом баланса (headless-матчи).

## Архитектура

- Бот — чистая функция `decide(view: PlayerView, memory, rng) → Command[]`, вызывается раз в 1 с (со смещением по id, чтобы не все в один тик).
- Бот видит **только** то, что видел бы игрок (тот же туман). Никакого читерства.
- Бот выдаёт **те же команды**, что клиент игрока. Отдельных «бот-API» в `sim` нет.
- Случайность — seeded PRNG бота (сид = сид матча + id игрока).

## Utility AI

Каждую секунду оцениваются действия, выбирается лучшее по полезности (с порогом, чтобы не дёргаться):

| Цель | Когда полезна |
| --- | --- |
| Экспансия | Есть нейтральные гексы рядом; первые минуты |
| Захват нейтрального города | Прогноз «победа», город в 8 гексах |
| Основать город | Есть валидный гекс, золото ≥ цены + резерв |
| Благоустройство | Гексы в радиусе городов с pop ≥ 80 % лимита |
| Налог | Мир → 10–15 %; враг у границы → 25–35 %; банкротство близко → выше |
| Набор отрядов | Сила фронта < 1,2 × видимой силы врага |
| Оборона фронта | Армии назначены на фронты или линии обороны (CR-002), резерв распределён по армиям; расстановка — `frontAllocator` |
| Наступление (стрелка) | Прогноз «победа» на участке, предпочитать цели, перерезающие дороги врага |
| Перестройка снабжения | Изолированный город, путь есть |

## Уровни

| Уровень | Отличия |
| --- | --- |
| Лёгкий | Реакция 3 с, не использует стрелки для окружений, налог фиксированный 20 % |
| Средний (по умолчанию) | Реакция 1 с, наступает на слабые участки |
| Сложный `[ПОЗЖЕ]` | Целенаправленно режет дороги, ищет котлы |

Новичку в первых 3 матчах — больше лёгких ботов по соседству.

## Имена ботов

Список вымышленных «государств» (`Вельская республика`, `Северный союз` …) в `packages/mapgen/names/`. Боты помечены значком только в списке игроков, не на карте.
