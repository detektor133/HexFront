# GDD 09 — Боты

Боты обязательны: заполняют лобби, делают первые матчи новичков интересными, служат инструментом баланса (headless-матчи).

## Архитектура

- Бот — чистая функция `decide(view: PlayerView, memory, rng) → Command[]`, вызывается раз в 1 с (со смещением по id, чтобы не все в один тик).
- Бот видит **только** то, что видел бы игрок (тот же туман). Никакого читерства.
- Бот выдаёт **те же команды**, что клиент игрока. Отдельных «бот-API» в `sim` нет.
- Случайность — seeded PRNG бота (сид = сид матча + id игрока).
- Уровень бота (`easy` или `medium`) передаётся необязательным массивом по id игрока рядом с массивом `bots` в `commanderCommands` и `botCommands`; отсутствующий уровень означает `medium`. Уровень не входит в `MatchState` и его хэш.
- **Военная часть бота — commander** (`07-controls.md`, «Автокомандование»): армии бота — с auto, отдельных приказов бот им не отдаёт. Utility AI ниже — экономика и крупные решения (налог, стройки, набор, дорога, когда нажать ▶ «Начать» на армии).

## Utility AI

Каждую секунду оцениваются действия, выбирается лучшее по полезности (с порогом, чтобы не дёргаться). Пороги — `10-balance.md`, «Боты». Экономический мозг (04/T23, `packages/sim/src/bots/economy.ts`) за одно решение делает не больше одной траты: дорога к изолированному городу (если путь есть) → набор (с учётом содержания солдат и отрядов) → основание города → благоустройство → улучшение города; налог, автопополнение и ▶ — в том же решении.

| Цель | Когда полезна |
| --- | --- |
| Захват нейтрального города | Прогноз «победа», город в 8 гексах |
| Основать город | Есть валидный гекс, золото ≥ цены + резерв |
| Благоустройство | Гексы в радиусе городов с pop ≥ 80 % лимита |
| Налог | Мир → 10–15 %; враг у границы → 25–35 %; банкротство близко → выше |
| Набор отрядов | С первой минуты: солдат у общей границы с соседом меньше `BOT_ARMY_RATIO` × его солдат у этой границы (по самому сильному соседу); содержание солдат и отрядов — не больше `BOT_ARMY_INCOME_SHARE` дохода. Бот просто набирает; долить отряд или создать новый — решает sim (`05-armies.md`, «Автопополнение») |
| Наступление (▶ «Начать» на армии с auto) | Цель — слабейший сосед (солдаты у общей границы, затем число городов); ▶ — армии на куске границы с ним при прогнозе «победа». Линию строит commander одной цепочкой: до ближайшего города цели, если он не дальше `BOT_LINE_MAX_DEPTH` гексов от фронта, иначе на `COMMANDER_LINE_DEPTH` |
| Прокладка дороги | Изолированный **свой** город, путь от сети столицы есть; причина каждой прокладки пишется в лог (после чего город стал изолирован) |
| Экспансия | Пока своя земля граничит с ничьей, а все армии заняты фронтами, бот держит отдельную армию экспансии (commander ведёт её как армию без врага); она не забирает все новые отряды — получатель набора по «Автопополнению» |

## Уровни

Уровни — параметры utility AI и commander.

| Уровень | Отличия |
| --- | --- |
| Лёгкий | Экономический мозг реагирует раз в 3 с, не нажимает ▶ «Начать», не использует линии наступления для окружений, налог фиксированный 20 %; commander работает без изменений |
| Средний (по умолчанию) | Реакция 1 с, наступает на слабые участки |
| Сложный `[ПОЗЖЕ]` | Целенаправленно режет дороги, ищет котлы |

Новичку в первых 3 матчах — больше лёгких ботов по соседству.
