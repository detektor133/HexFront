# GDD 05 — Армии

## Модель

- Армия = **однотипный** отряд: `{ id, owner, type, soldiers, org, hex, order, supplyLevel }`.
- В одном гексе до **3 армий** одного игрока. Армии разных игроков в одном гексе не стоят никогда (вход в занятый врагом гекс = атака).
- Лимит армий игрока: **4 + 2 × число городов** (командная ёмкость). Делает спам мелкими отрядами невыгодным без жёсткого потолка.

## Типы войск

| | Пехота `infantry` | Бронетехника `armor` | Артиллерия `artillery` |
| --- | --- | --- | --- |
| Роль | Держит фронт | Прорыв на равнине | Огонь со второй линии |
| Цена за солдата | 1 чел. + 0,1 з. | 1 чел. + 1,0 з. | 1 чел. + 0,6 з. |
| Содержание, з./с на 100 | 0,3 | 1,2 | 0,8 |
| Атака | 1,0 | 2,0 | — (обстрел) |
| Оборона | 1,2 | 0,9 | 0,6 |
| Скорость: равнина / лес, холмы / горы / пустыня | 1,0 / 0,7 / 0,5 / 0,9 | 1,6 / 0,8 / 0,5 / 1,4 | 0,7 / 0,5 / 0,4 / 0,7 |
| Снабжение на солдата | 1,0 | 2,5 | 1,5 |
| Захват гексов | да | да | **нет** |

Детали артиллерии и боя — `06-combat.md`.

## Набор

- В карточке города: тип + количество (ползунок, шаг 50, минимум 50).
- Люди берутся из городского гекса и колец 1–2 пропорционально населению; ни один гекс не опускается ниже 10 % своего лимита. Максимум набора ограничен этим.
- Золото списывается сразу. Время: пехота 8 с + 1 с/100, бронетехника 15 с + 2 с/100, артиллерия 12 с + 1,5 с/100.
- Очередь: одна единица набора на город одновременно.
- Новая армия появляется в городе с организованностью 100. Если в гексе уже 3 армии — появляется в ближайшем своём свободном гексе.

## Движение

```
время перехода = terrainMoveTime(куда) / speed(type, terrain)
               × 0,5 если оба гекса дорожные
               + 1,0 с если пересекается река
               × 2 если гекс-назначение соседствует с вражеской армией (зона контроля)
               ÷ 0,75 если supplyLevel < 50 % (скорость ×0,75)
```

- Путь — A* по этим весам. Движение дискретное (гекс за гексом), клиент интерполирует визуально.
- Вход в гекс = начало перехода; армия считается в новом гексе по завершении.
- `terrainMoveTime` и `speed` берутся по местности гекса-назначения (перевал — как холмы). Время перехода считается в момент его начала.
- Бонус дороги — по **любым** дорогам, если оба гекса дорожные, независимо от владельца: наступать по вражеской трассе быстро, поэтому её выгодно перерезать. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-25]`
- **Полный гекс** (3 своих армии): путь прокладывается в обход полных гексов; если гекс на пути заполнился уже в дороге — армия **ждёт** перед ним, пока не освободится место. Правило «не больше 3 армий в гексе» не нарушается никогда. Цель — полный гекс → отказ. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-25]`
- **Препятствие на пути**: путь не пересчитывается. Если следующий гекс занят врагом (армия, гарнизон, ополчение) — армия атакует его (`06-combat.md`); если гекс стал непроходимым (для артиллерии — перестал быть своим) — армия останавливается и ждёт нового приказа. `[ДИЗАЙН-РЕШЕНИЕ 2026-09-25]`

## Захват

- Армия любого размера (даже 1 солдат) занимает **пустой** нейтральный или вражеский гекс по завершении перехода.
- Гекс с вражеской армией, гарнизоном или ополчением — только через бой.
- Артиллерия входит только в свои гексы.
- Гекс захватывается и на промежуточных шагах пути — каждый пройденный пустой гекс становится своим.

## Разделение и слияние

- Разделить: любое число 1…soldiers−1, мгновенно, новая армия в том же гексе (если есть место и не превышен лимит армий), организованность копируется.
- Слить: однотипные армии в одном гексе; организованность = средневзвешенная по солдатам.

## Приказы (`order`)

| Приказ | Поведение |
| --- | --- |
| `idle` | Стоит, обороняется |
| `move(path)` | Идёт по пути; атакует, если путь упирается во врага |
| `attack(hex)` | Атакует соседний гекс |
| `hold` | Стоит, не атакует никогда (даже автофронтом) |
| `expand` | Автоматически занимает ближайшие нейтральные гексы, пока они есть рядом (ранняя игра). Цель — ближайший по времени хода нейтральный пустой гекс, **соседний со своей территорией**; гексы, куда уже идёт другая своя армия на экспансии, пропускаются. Нет таких гексов → приказ сменяется на `idle`. Артиллерии приказ недоступен `[ДИЗАЙН-РЕШЕНИЕ 2026-09-25]` |
| `front(frontId)` | Под управлением автофронта (`07-controls.md`) |
| `bombard(targetArmyId?)` | Только артиллерия: фокус огня, иначе автоцель |
