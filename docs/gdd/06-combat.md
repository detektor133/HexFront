# GDD 06 — Бой, отступление, артиллерия

Бой **детерминирован**: одинаковые входные данные → одинаковый результат. Случайности нет. Это позволяет честный PvP, прогноз до атаки, реплеи и тесты.

## Сила сторон

```
Атака = Σ атакующих: soldiers × atk(type) × supplyMult
        × flankMult × artilleryBonus × riverMult

Оборона = Σ защитников в гексе: soldiers × def(type) × supplyMult
          × terrainDef × fortMult × cityMult

supplyMult     = 0,5 + 0,5 × supplyLevel
flankMult      = 1 + 0,15 × (число разных направлений атаки − 1), максимум 1,3
artilleryBonus = 1,3, если целевой гекс в радиусе 2 от своей артиллерии (≥ 100 солдат), иначе 1,0 (не складывается)
riverMult      = 0,7 для атакующих через ребро-реку
terrainDef     — из 01-map.md;  fortMult = 1,4;  cityMult = 1,3
```

Все атакующие один гекс (из любых соседних гексов) участвуют в одном бою. Защищаются все отряды в гексе (+ополчение/гарнизон).

## Потери и организованность (каждый тик)

```
потери атакующих/с = Оборона × CASUALTY_RATE   // 0,010
потери защитников/с = Атака × CASUALTY_RATE
  — распределяются по отрядам стороны пропорционально soldiers

потеря org защитника/с = clamp(6 × Атака / Оборона, 1, 20)
потеря org атакующего/с = clamp(6 × Оборона / Атака, 1, 20)
```

Бой решает **организованность**, а не полное уничтожение: отряды ломаются и отступают задолго до гибели.

## Исход

| Событие | Результат |
| --- | --- |
| org защитника = 0 | Защитник **отступает**. Когда в гексе не осталось защитников — атакующий отряд с наибольшей силой входит в гекс (захват) |
| org атакующего = 0 | Атака прекращается, атакующий остаётся в своём гексе |
| soldiers = 0 | Армия уничтожена |
| Ополчение/гарнизон org = 0 | Город захвачен (ополчение не отступает) |

## Отступление

Проигравший отряд **не исчезает**:

1. Выбирается гекс отступления: соседний **свой** проходимый гекс, в котором < 3 своих отрядов. Приоритет: не соседствует с атакующими → выше `supplyLevel` → меньший `hexId`.
2. Потеря 5 % солдат (брошенное снаряжение).
3. Отступление: время хода ×0,7, отряд не принимает приказы, при атаке во время отступления получает потери ×2.
4. По прибытии org = 20 (затем обычная регенерация). Если её снова атакуют — возможна цепочка отступлений (разгром).
5. **Нет гекса для отступления** (все соседи вражеские, вода или переполнены) → **капитуляция**: отряд уничтожен. Это и есть смысл окружения.

Регенерация org: +4/с вне боя при `supplyLevel ≥ 50 %` и без банкротства.

## Артиллерия

- **Обстрел**: каждую секунду бьёт по одному вражескому отряду в радиусе 2 гексов (в зоне видимости).
  - урон солдатам/с = soldiers_арт × 0,004 × supplyMult;
  - урон org/с = soldiers_арт × 0,002.
- **Автоцель**: вражеский отряд, атакующий наш гекс → отряд на соседнем с нашей территорией гексе с наибольшей численностью → вражеская артиллерия. Ручной фокус (`bombard(id)`) перекрывает.
- **Поддержка**: +30 % к атаке своих отрядов по гексам в её радиусе (см. `artilleryBonus`).
- **Не атакует и не захватывает.** Входит только в свои гексы.
- **Уязвимость**: если враг атакует гекс, где артиллерия одна — она немедленно отступает (−10 % солдат). Если с ней другие отряды — защищается вместе с ними (оборона 0,6) и отступает вместе.
- Автофронт ставит артиллерию на 1 гекс позади линии фронта.

## Прогноз боя

Чистая функция `forecastBattle(view, attackers, targetHex)` в `sim`, используется UI до подтверждения атаки.

```
tDef = средневзв. org защитников / потеря org защитника в секунду
tAtt = средневзв. org атакующих / потеря org атакующего в секунду
исход = tDef < tAtt × 0,9 → «победа»;  tAtt < tDef × 0,9 → «поражение»;  иначе «упорный бой»
время = min(tDef, tAtt)
потери, % = скорость потерь × время / soldiers стороны
```

- Считается **только по видимым данным** игрока: неизвестная снабжённость врага = 100 %, невидимые отряды не учитываются (отсюда реальная неопределённость).
- UI: плашка у стрелки/цели — «Победа · потери ~28 %», «Упорный бой», «Поражение» (цвета — в `art/ui.md`).
