## Команды проверки

| Команда | Что делает |
| --- | --- |
| `pnpm ai-check --changed` | в работе: lint/prettier изменённых файлов, типы, затронутые тесты; тихий вывод |
| `pnpm ai-check --full` | перед коммитом, один раз: типы, lint, depcheck, tokens, все тесты с покрытием |
| `pnpm ai-check --staged` | lint staged-файлов (вызывает хук pre-commit) |
| `pnpm visual` | сравнение скриншотов `/dev/map` с эталонами: «прошло/не прошло, X %, путь к diff» |
| `pnpm visual --update` | осознанно обновить эталоны (`apps/client/tests/visual/baseline/`) |
| `pnpm report:match --seeds N` | N матчей ботов, метрики JSON, графики PNG → `docs/reports/match/`, сводка ≤ 20 строк |
| `pnpm verify [--changed]` | **основная проверка**: build → типы → lint → тесты → visual; лог в `.ai-logs/verify-*.log`, в консоль итог ≤ 20 строк |
| `pnpm check` | полный прогон с подробным выводом (CI); для агента — `ai-check --full` |

Хуки (`.githooks/`, включает `pnpm install`): pre-commit — lint staged; commit-msg — заголовок ≤ 72, допустимые области, трейлер; pre-push — lint и commit-check ветки. `gh` не установлен: CI смотреть через REST API GitHub (curl).

## Правила работы (экономия токенов)

- **Проверка — только `pnpm verify`** (`--changed` в работе, без флага перед коммитом). Детали ошибок — `grep -n -C3 "FAIL\|error" .ai-logs/<лог>`, а не перезапуск. Stop-хук сам гоняет `verify --changed`, пока в дереве есть изменения: красный — ход не закончить.
- Длинные команды — на переднем плане с `timeout`; без фоновых задач и опроса.
- **Картинки и браузер запрещены** (Read PNG/WebM/MP4, браузерные MCP, `pnpm dev`, Playwright — в deny). Визуальную проблему описывать по тексту `pnpm visual`: процент, область x/y/ширина/высота, селекторы элементов.
- Независимые команды объединять в один вызов.

- Читать через `grep -n` с контекстом; файл целиком — только тот, что правишь.
- Многострочный текст (коммит, отчёт, файл) — через Write во временный файл, не heredoc.
- Дизайн-вопросы — одним списком и остановиться; код до ответа не начинать.
- Отчёт в чате — до 10 строк со ссылкой на `docs/reports/`; все ответы владельцу — по-русски.
- Сгенерированные файлы токенов (`apps/client/src/theme/tokens.*`) не форматировать prettier — `pnpm tokens`.
- Одна задача — одна сессия; `STATUS.md` обновлять в конце, коммит, push, дождаться CI.
