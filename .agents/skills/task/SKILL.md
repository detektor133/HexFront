# $task <этап/задача>

Исполнитель владеет только кодом продукта. Не создавай, не меняй и не удаляй тесты: после
принятия кода их напишет отдельный автор тестов. Исключение — прямое ручное поручение владельца
изменить конкретный тест вне автоматической очереди.

Если запрос содержит `ОБЯЗАТЕЛЬНЫЙ ВОЗВРАТ REVIEWER`, исправь только перечисленный дефект
продукта. Возврат с `КОД:` содержит критерий, наблюдаемое поведение и путь; не расширяй его
тестовой работой. `ТЕСТ:` исполнителю не передаётся и не исправляется им.

1. Сверь ветку, чистоту дерева и зелёный CI для HEAD. При `продолжить` допускается только
   незакоммиченная работа этой задачи.
2. Прочитай блок задачи, родителя, STATUS, последние решения и нужные разделы документации.
3. Реализуй минимальный код на реальном пути вызова. Не меняй тесты.
4. Запусти `pnpm verify --changed`; исправь ошибки кода, типов, lint и форматирования.
5. Закоммить только код и документацию задачи с трейлером `Этап: NN/Tn`, отметь `[~]`, push.

Если критерий не определён документами, запиши вопрос в `docs/QUESTIONS.md`, закоммить docs-
изменение и остановись. Не открывай браузер, не запускай `pnpm dev`, Playwright или ботоматчи.
