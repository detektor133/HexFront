# $code

Прочитай задачу дословно и падающие тесты. Измени только код, конфиги пакетов и источники в разрешениях роли. Тесты, docs, отметки `[x]`, скиллы и таймауты не изменяй. Сохрани архитектуру проекта и минимальный diff. Если тест считает требование неверным, первой строкой ответа напиши `ТЕСТ: <причина>` и не меняй тест.

Во время работы запускай только тесты затронутых файлов (`pnpm exec vitest run <файлы>`) и `pnpm ai-check --changed`. Перед коммитом один раз запусти полный `pnpm verify`; коммить можно только после его успеха. Таймаут считается красным результатом, таймауты поднимать запрещено. Если полный прогон красный, исправь причину, проверь только упавшие файлы и выполни ещё один полный прогон. Больше двух полных прогонов за ход запрещено: остановись и отчитайся. Трейлер коммита: `Этап: NN/Tn`.
