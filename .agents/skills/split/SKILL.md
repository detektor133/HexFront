# $split <этап/задача>

1. Прочитай только блок исходной задачи через `rg -l`, затем `rg -n -C2` по 1–2 файлам.
2. Учти незакоммиченную работу командой `git stash show -p --stat "stash@{0}"`.
3. Разбей задачу на Tna, Tnb и далее: одна подсистема на подзадачу, не более 4 критериев в каждой. Приёмочные матчи сделай последней подзадачей только если они есть в критериях исходной задачи; самому их не добавляй. Для задач интерфейса последней подзадачей сделай скриншоты для просмотра владельцем.
4. Запиши подзадачи в файл этапа непосредственно под исходной задачей и обнови `docs/STATUS.md`.
5. Код не трогай. Создай коммит области `docs` с трейлером `Этап: <NN>/infra`, затем push.

Если критерий нельзя однозначно отнести к одной подсистеме, оставь его в последней подзадаче и явно укажи зависимость.
