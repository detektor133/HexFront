# $split <этап/задача>

1. Прочитай только блок исходной задачи через `rg -l`, затем `rg -n -C2` по 1–2 файлам.
2. Разбей задачу на Tna, Tnb и далее: одна подсистема на подзадачу, не более 4 критериев в каждой. Приёмочные матчи сделай последней подзадачей только если они есть в критериях исходной задачи; самому их не добавляй. Для задач интерфейса последней подзадачей сделай скриншоты для просмотра владельцем. Запреты исходной задачи копируются дословно в каждую подзадачу; при критерии скорости каждая подзадача с кодом получает минутный замер.
3. В коммите добавь таблицу трассировки: каждое предложение и каждый критерий исходной задачи должны быть перечислены отдельными строками с номером подзадачи. Если строка не покрыта подзадачей, разбиение запрещено.
4. Последней подзадачей всегда добавь «Проверка родителя»: сверить все предложения и критерии исходной задачи с тестами и замерами. Только эта подзадача может отметить исходную задачу как `[x]`.
5. Подзадачу повторно не дроби. Если подзадача велика для одного захода, остановись и спроси владельца.
6. Запиши подзадачи в файл этапа непосредственно под исходной задачей, добавь таблицу трассировки и обнови `docs/STATUS.md`.
7. Код не трогай. Создай коммит области `docs` с трейлером `Этап: <NN>/infra`, затем push.

Если критерий нельзя однозначно отнести к одной подсистеме, оставь его в последней подзадаче и явно укажи зависимость.
