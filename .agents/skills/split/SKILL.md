# $split <этап/задача>

1. Найди исходную задачу через `rg -l`, затем прочитай её блок целиком — от строки задачи до следующей задачи — и блок родительской задачи с её запретами, без сокращений (не через `-C2`).
2. Разбей задачу на Tna, Tnb и далее: одна подсистема на подзадачу. Приёмочные матчи сделай последней подзадачей только если они есть в критериях исходной задачи; самому их не добавляй. Запреты исходной задачи копируются дословно в каждую подзадачу; при критерии скорости каждая подзадача с кодом получает минутный замер.
3. В коммите добавь таблицу трассировки: каждое предложение и каждый критерий исходной задачи должны быть перечислены отдельными строками с номером подзадачи. Если строка не покрыта подзадачей, разбиение запрещено.
4. Отдельной подзадачи «Проверка родителя» нет: каждый критерий исходной задачи — критерий ровно одной подзадачи (таблица трассировки), его приёмочный тест пишет `$spec` этой подзадачи. Исходную задачу отмечает `[x]` ревью последней подзадачи, когда все подзадачи `[x]`.
5. Подзадачу повторно не дроби. Если подзадача велика для одного захода, остановись и спроси владельца.
6. Запиши подзадачи в файл этапа непосредственно под исходной задачей, добавь таблицу трассировки и обнови `docs/STATUS.md`: в строке «Очередь» замени исходную задачу её подзадачами по порядку.
7. Код не трогай. Создай коммит области `docs` с трейлером `Этап: <NN>/infra`, затем push.

Если критерий нельзя однозначно отнести к одной подсистеме, оставь его в последней подзадаче и явно укажи зависимость.
