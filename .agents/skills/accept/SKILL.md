# $accept <этап/задача>

1. Убедись, что рабочее дерево чистое. При грязном дереве остановись.
2. Сначала проверь критерии задачи. Если в них нет ботоматча, не запускай матчи и ответь ровно: «Для этой задачи приёмка — тесты».
3. Если в критериях есть ботоматч, выполни один `pnpm report:match --seeds N`, где N задан критериями задачи.
4. Для ботоматча прочитай текстовую сводку команды и текстовые артефакты `metrics.json` и CSV. PNG читать запрещено. Не запускай verify, матчи повторно, дополнительные диагностики или метрики.
5. Для каждого критерия запиши выполнен/не выполнен с числом. Код не правь.
6. Запиши результат в `docs/reports/stage-NN.md` и создай коммит области `docs` с трейлером `Этап: <NN>/infra`.
