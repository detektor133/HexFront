# $tests

Прочитай задачу, её «План» и «Сторожа». Напиши тест на каждый пункт приёмки, каждый сторож и каждый краевой случай. Тесты, которые задача прямо перечисляет как заменяемые, замени; другие существующие тесты не ослабляй. Код, документацию, скиллы и таймауты не изменяй. Запусти профильные тесты и зафиксируй, что новые проверки падают на текущем коде. Создай тестовый коммит с трейлером `Этап: NN/Tn`; полный verify для роли tester не является условием зелёного результата.
