# $next

1. Текущий этап — из `docs/STATUS.md`.
2. Первая невыполненная задача с учётом порядка в STATUS и зависимостей: `grep -n "^- \[ \]" docs/stages/stage-<NN>-*.md`.
3. Если все задачи этапа отмечены — не начинай новый этап, а скажи владельцу: «Этап NN закрыт по задачам, запусти $stage-close».
4. Если задача заблокирована открытым вопросом в `docs/QUESTIONS.md` — бери следующую незаблокированную и скажи, какую пропустил и почему.
5. Выполни выбранную задачу ровно по шагам скилла `$task`. Одна задача за сессию.
