# $next

1. В начале выполни `pnpm ci:wait` для `HEAD`. Красный результат сначала исправь; задачу не выбирай до зелёного результата. Затем проверь `git status --short`; если дерево не чистое, остановись и сообщи владельцу.
2. Текущий этап — из `docs/STATUS.md`.
3. Первая невыполненная задача с учётом порядка в STATUS и зависимостей: через `rg -l`, затем `rg -n -C2 "^- \[ \]" <файл> | Select-Object -First 80`.
4. Если все задачи этапа отмечены — не начинай новый этап, а скажи владельцу: «Этап NN закрыт по задачам, запусти $stage-close».
5. Если задача заблокирована открытым вопросом в `docs/QUESTIONS.md` — бери следующую незаблокированную и скажи, какую пропустил и почему.
6. Выполни выбранную задачу ровно по шагам скилла `$task`. Одна задача за сессию; после push CI не жди.
