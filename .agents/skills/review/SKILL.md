# $review

Скилл запускается владельцем вручную в новой сессии или ролью reviewer. Прочитай блок задачи целиком и блок её родителя с запретами, без сокращений, и diff всех коммитов с её трейлером. Полный `pnpm verify` не запускай: его выполняет CI на этом коммите. Для каждого критерия и сторожа найди тест, измерение или команду чтением. По коду проверь, что каждый критерий выполнен на реальном пути вызова, а не только во вспомогательной функции, которую вызывает тест; хардкод или обходной путь вместо механизма из задачи — `ВОЗВРАТ`. На каждый запрет выполни `rg` по изменённым файлам и приведи вывод. При критерии скорости запусти только замер `pnpm --filter @hexfront/bench full-match --players=30,100 --minutes=1` и сравни с базой задачи.

Первой строкой ответа напиши `OK`, если всё подтверждено, иначе `ВОЗВРАТ` и список `пункт — файл:строка — что не так`. Код и тесты не изменяй. При `OK` замени `- [~]` на `- [x]`, добавь строку в отчёт и создай docs-коммит с трейлером `Этап: NN/Tn`. При `ВОЗВРАТ` замени `- [~]` на `- [ ]`, под задачей добавь строку «Возврат ревью:» со списком и создай такой же docs-коммит. В обоих случаях — push ветки.
