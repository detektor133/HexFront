# $review

Прочитай задачу дословно и diff всех коммитов с её трейлером. Сам запусти полный `pnpm verify`. Для каждого критерия и сторожа найди тест, измерение или команду. При критерии скорости запусти `pnpm --filter @hexfront/bench full-match --players=30,100 --minutes=1` и сравни с базой задачи.

Первой строкой ответа напиши `OK`, если всё подтверждено, иначе `ВОЗВРАТ` и список `пункт — файл:строка — что не так`. Код и тесты не изменяй. При `OK` отметь задачу, добавь строку в отчёт и создай docs-коммит с трейлером `Этап: NN/Tn`.
