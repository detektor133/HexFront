# $bug <описание>

1. Прочитай раздел «Баги и замечания» в `docs/PROCESS.md` и `docs/BUGS.md`.
2. Проверь дубли по месту, симптому и способу воспроизведения. Дубль дополни в существующей строке, новую строку не создавай.
3. Определи класс по таблице в `docs/PROCESS.md` и добавь строку в `docs/BUGS.md` в формате реестра.
4. Для Б1 добавь задачу в конец файла текущего этапа и поставь её первой в строке «Очередь» в `docs/STATUS.md`. Для Б3 добавь строку в T28. Для Б2 оставь только строку в `docs/BUGS.md`.
5. Код не трогай и воспроизведение не запускай.
6. Закоммить изменения с областью `docs` и трейлером `Этап: NN`, затем запушь ветку.
7. Ответ владельцу — 2–3 строки.
