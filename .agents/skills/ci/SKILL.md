# $ci

`gh` не установлен. CI смотреть через REST API GitHub (curl), как уже делалось в проекте.

1. SHA: `git rev-parse HEAD`.
2. Один запрос: `GET /repos/<owner>/<repo>/actions/runs?head_sha=<sha>` — статус и вывод.
3. Если ещё идёт — одна команда ожидания на переднем плане: `sleep 120` и повторный запрос, не больше 5 раз, в одном вызове скрипта, а не отдельными шагами.
4. Зелёный — одна строка в отчёте. Красный — запроси логи упавшего job, `grep` по ошибке, почини, коммит, push, снова `$ci`. Красный CI — задача не готова.
