# $stage-close

1. `grep -n "^- \[ \]\|^- \[~\]" docs/stages/stage-<NN>-*.md`. Если есть невыполненные задачи или задачи, ждущие ревью, — перечисли их и остановись.
2. Один полный прогон `pnpm verify` (быстрый уровень тестов); тяжёлые тесты — workflow `slow`, агентный цикл дождался его зелёным до `$stage-close`, вручную — `pnpm ci:wait --workflow=slow.yml`. Если баланс или боты менялись в этапе — `pnpm report:match --seeds 3` и сравнение с базой (только текстовая сводка).
3. `docs/reports/stage-<NN>.md`: что сделано по задачам, что перенесено и почему, открытые вопросы, пути к PNG эталонов и графиков (сами картинки не открывать, их смотрит владелец), итог verify, известные риски.
4. `docs/STATUS.md` перепиши целиком, до 3 КБ: таблица, строка «Очередь», «Блокеры и открытые вопросы», «Следующая сессия» — этап NN закрыт, следующий этап, его первая задача, что прочитать. Всё остальное (решения, архив сессий) перенеси в `docs/reports/stage-<NN>.md`, если его там нет. Таблицу пиши ровно по шаблону, без других столбцов и строк: агентный цикл читает поля «Текущий этап» и «Ветка», другая таблица его останавливает. «Ветка» до шага 7 — прежняя `stage-<NN>`: по ней цикл видит, что этап закрыт и ждёт мержа PR.

```
| Поле | Значение |
| --- | --- |
| Текущий этап | <NN+1> — <название следующего этапа> |
| Текущая задача | <первая задача следующего этапа> |
| Ветка | `stage-<NN>` |
| Последнее обновление | <ГГГГ-ММ-ДД> |
```

5. Коммит `docs:` с трейлером `Этап: <NN>/close`, push, CI по скиллу `$ci`.
6. Отчёт владельцу до 10 строк и ссылка на отчёт этапа. Следующий этап сам не начинай.
7. После мержа PR этапа создай ветку следующего этапа от `main`, запушь её с upstream и запиши её имя в поле «Ветка» файла `docs/STATUS.md`. Строка «Очередь» нового этапа — только номера задач через «→» в порядке раздела «Порядок» файла этапа, без пояснений. Коммит `docs` с трейлером `Этап: <NN+1>/infra`, push.

Повторный вызов: если этап уже закрыт (номер «Текущий этап» в `docs/STATUS.md` отличается от номера в поле «Ветка»), шаги 1–6 не повторяй. Ветка этапа смёржена в `main` (`git fetch origin main`, `git merge-base --is-ancestor HEAD origin/main`) — выполни только шаг 7; не смёржена — скажи ровно: «PR этапа NN не смёржен» и остановись.
