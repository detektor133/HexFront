# $plan

Прочитай текст задачи дословно и все файлы пути, который она меняет. Если задача пришла из Issue, перенеси текст Issue в файл текущего этапа дословно, добавь ссылку и новый номер `T\d+[a-z0-9]*`. Под задачей запиши «План» с файлами, функциями, источниками полей и удаляемым кодом. Под ним запиши «Сторожа» — проверяемое утверждение на каждый запрет и критерий.

Код и тесты не изменяй. Если изменился `docs/QUESTIONS.md`, заверши ход с причиной. Создай документационный коммит с трейлером `Этап: NN/Tn` только после полного `pnpm verify`.
