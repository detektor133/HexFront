# $decide <решения владельца>

Решения уже приняты владельцем. Не обсуждай их и не предлагай альтернатив; если решение противоречит другим разделам документов — перечисли конфликты и остановись.

1. Для каждого решения найди все упоминания правила и констант: `grep -rn "<термин|КОНСТАНТА>" docs/`.
2. Внеси изменения в `docs/gdd/*.md`; числа — только в `docs/gdd/10-balance.md`, новые числа с пометкой `[ТЮНИНГ]`.
3. Если решение меняет задачи — правь файл этапа: новые задачи или изменённые критерии приёмки.
4. Строка в `docs/DECISIONS.md` на каждое решение: дата, суть, затронутые файлы.
5. Закрой соответствующие вопросы в `docs/QUESTIONS.md`.
6. `docs/STATUS.md`: какие задачи затронуты и что делать дальше.
7. Код и тесты не трогать. Один коммит `docs:` с трейлером этапа, push.
8. Отчёт владельцу до 5 строк: какие файлы изменены, какие задачи затронуты.
