# Hexfront — пакет документации для AI-агента

Рабочее название: **Hexfront** (кодовое имя, финальное название TBD).
Сессионная браузерная/мобильная стратегия: гекс-карта, города, дороги-линии снабжения,
армии с фронтами, окружения. «HOI4 за 20 минут».

## Как пользоваться

1. Создай пустой репозиторий, скопируй туда содержимое этой папки (`README.md`, `CLAUDE.md`, `AGENTS.md`, `.gitmessage`, `.github/`, `docs/`).
2. Открой агента (Claude Code или другой) в корне репо.
3. Дай команду:

   > Прочитай `AGENTS.md` и `docs/README.md`. Выполни `docs/stages/stage-01-foundation.md`. Работай по задачам по порядку, после каждой задачи CI должен быть зелёным. В конце этапа дай отчёт по чек-листу приёмки.

4. Проверь отчёт и чек-лист приёмки сам (особенно визуальные пункты — смотри скриншоты).
5. Следующий этап — той же командой с другим файлом. **Не запускай следующий этап, пока текущий не принят.**

## Когда нужен ты, а не агент

- Решения по балансу, которые отмечены `[ДИЗАЙН-РЕШЕНИЕ]` в доках.
- Плейтесты (этап 05 — go/no-go).
- Визуальная приёмка: агент не может оценить «выглядит ли это как нейросеть».
- Иконка, логотип, ключевой арт — заказать у человека (см. `docs/art/style-guide.md`, раздел «Что делает человек»).

## Шпаргалка команд агенту

| Ситуация | Что сказать |
| --- | --- |
| Начать этап | «Прочитай `AGENTS.md`, `docs/STATUS.md` и `docs/stages/stage-0N-*.md`. Составь план по задачам, покажи мне, после подтверждения начинай с первой.» |
| Продолжить после перерыва / новая сессия | «Прочитай `AGENTS.md` и `docs/STATUS.md`, продолжай с текущей задачи.» |
| Поменять число | «Поменяй `TAX_MAX` на 50 % по `docs/PROCESS.md` (размер S).» |
| Поменять правило | «Изменение размера M: <что и как>. Найди все затронутые места в доках, покажи список, после подтверждения примени по `docs/PROCESS.md`.» |
| Большая идея | «Составь CR по шаблону `docs/changes/CR-000-template.md`: <идея>. Не применяй, пока я не поставлю статус "принят".» |
| Баг | «Баг: <что вижу, где, как воспроизвести>. Сначала напиши падающий тест, потом исправь. Не меняй поведение, описанное в доках.» |
| Агент застрял / ходит по кругу | «Стоп. Не пробуй больше. Опиши: что ожидалось, что происходит, три гипотезы причины и как проверить каждую.» |
| Конец сессии | «Обнови `docs/STATUS.md` и закоммить.» |

Процесс изменений целиком — в `docs/PROCESS.md`.

## Если агент начал «улучшать» дизайн или выдумывать механики

Скажи: «Остановись. Спецификация в `docs/gdd` и `docs/art` — источник истины. Если считаешь, что там ошибка — предложи изменение в `docs/CHANGELOG-proposals.md`, не меняй код в обход документа.»
